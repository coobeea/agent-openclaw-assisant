# 经验库 - 建立说明

> **为什么要建立经验库？如何使用？**

---

## 🎯 为什么需要经验库？

### 问题背景

**之前的状况**:
```
遇到问题 → 排查 → 解决 → 忘记
  ↓
下次遇到同样问题 → 又要重新排查 → 又要重新解决
  ↓
重复循环，浪费大量时间
```

**飞书配对问题实例**:
- 2026-03-11 上午：反复尝试配对，操作了错误的 `paired.json`
- 持续2小时，陷入死循环
- **原因**：不知道OpenClaw使用 `allowFrom.json`，没有经验记录

---

## ✅ 建立经验库后

### 新的工作流程

```
遇到问题
  ↓
📚 第1步: 查经验库（30秒）
  ├─ 找到 → 按文档操作（5分钟）→ 解决 ✅
  └─ 没有 → 进入排查
  ↓
🔍 第2步: 排查问题（首次，可能需要时间）
  ↓
✅ 第3步: 解决并记录
  ↓
📝 第4步: 写入经验库
  ↓
下次遇到同样问题 → 直接查经验库（30秒）→ 解决 ✅
```

**效果**:
- 首次问题：需要排查时间
- 后续相同问题：30秒查找 + 5分钟操作 = 解决
- **时间节省**：80%+

## 🔍 如何查找经验

### 方式 1: 通过索引

```bash
cat docs/经验积累/README.md
```

索引包含：
- 问题分类
- 文档列表
- 重要程度标记

### 方式 2: 关键词搜索

```bash
# 搜索所有经验文档
grep -r "配对" docs/经验积累/

# 使用 rg（更快）
rg "配对" docs/经验积累/
```

### 方式 3: AI助手自动查询

在 `AGENTS.md` 中配置，让AI助手：
1. 收到问题时自动查询经验库
2. 优先使用已有方案
3. 没有经验时才排查

## 📝 如何记录经验

### 记录时机

**必须记录**:
- ✅ 解决了任何问题
- ✅ 发现了错误理解
- ✅ 找到了更好的方案

**记录内容**:
1. **问题描述** - 用户看到什么
2. **根本原因** - 技术层面的真实原因
3. **错误理解** - 之前为什么会错（重要！）
4. **正确方案** - 完整的解决步骤
5. **源码引用** - 相关源码位置
6. **预防措施** - 如何避免再次发生

### 文档模板

使用 `docs/经验积累/经验库-使用检查清单.md` 中的模板。
