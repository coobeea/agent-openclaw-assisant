# 经验库使用 - 检查清单

> **用于AI助手和维护人员**

---

## ✅ 处理问题前检查

### 1. 必须查经验库

- [ ] 已阅读 `docs/经验积累/README.md` 索引
- [ ] 已搜索相关关键词
- [ ] 已找到并阅读相关文档

### 2. 理解问题

- [ ] 已理解问题的根本原因
- [ ] 已查看源码验证理解
- [ ] 已确认文件结构和路径

### 3. 执行方案

- [ ] 已按文档步骤操作
- [ ] 已验证每个步骤的结果
- [ ] 已测试最终效果

---

## ✅ 解决问题后检查

### 1. 记录经验

- [ ] 已创建经验文档（问题+原因+方案）
- [ ] 已更新 `docs/经验积累/README.md` 索引
- [ ] 已包含源码位置和原理解释

### 2. 更新工具

- [ ] 已修复/更新相关脚本
- [ ] 已测试脚本可用性
- [ ] 已更新文档中的命令示例

### 3. 预防措施

- [ ] 已添加到健康检查（如适用）
- [ ] 已创建自动化工具（如适用）
- [ ] 已更新README提醒

## 🎯 快速搜索

### 按问题类型

```bash
# 配对问题
grep -r "配对\|pairing" docs/经验积累/

# 模型问题
grep -r "model\|模型" docs/经验积累/

# 启动问题
grep -r "启动\|start" docs/经验积累/

# 配置问题
grep -r "配置\|config" docs/经验积累/
```

### 按关键词

```bash
# 搜索任意关键词
grep -r "关键词" docs/经验积累/

# 使用 rg（更快）
rg "关键词" docs/经验积累/
```
