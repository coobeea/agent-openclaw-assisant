## 🎯 经验库的工作流程

### AI助手使用经验库

```
收到用户问题
  ↓
📚 Step 1: 查询经验库
  - 读取 docs/经验积累/README.md
  - 搜索相关关键词
  ↓
找到相关经验？
  ├─ 是 → 阅读经验文档 → 按文档操作 → 解决 ✅
  └─ 否 → 排查问题 → 解决 → 记录新经验 → 完成 ✅
```

### 用户使用经验库

```
遇到问题
  ↓
打开 docs/经验积累/README.md
  ↓
查找相关经验
  ├─ 找到 → 运行对应的自动化脚本 → 解决 ✅
  └─ 没找到 → 联系支持 → 问题解决后更新经验库
```

## 🎯 核心原则

### 1. 先查后做

**每次处理问题前，必须先查经验库**

```bash
cat docs/经验积累/README.md
grep -r "关键词" docs/经验积累/
```

### 2. 理解原理

**不要只看步骤，要理解为什么**

- 阅读"根本原因"部分
- 查看源码引用
- 理解技术机制

### 3. 及时记录

**解决问题后，立即记录经验**

- 趁记忆新鲜
- 包含完整信息
- 更新索引

### 4. 持续优化

**经验库是活的，需要持续更新**

- 发现更好方案时更新
- 发现错误时修正
- 标记过时的文档
