# 🎯 处理问题 - 必读指南

> **每次处理问题前，必须先读这个文档！**

---

## 🚨 核心原则

### 1. 先查经验库

**在处理任何问题前**，必须：

```bash
# 查看经验库索引
cat docs/经验积累/README.md

# 搜索相关经验
grep -r "关键词" docs/经验积累/
```

**为什么**：
- ❌ 不查经验库 = 重复犯错 = 浪费时间
- ✅ 查经验库 = 快速定位 = 高效解决

## 🔍 查找经验的步骤

### 步骤 1: 确定问题类型

| 问题类型 | 关键词 | 优先查看 |
|---------|-------|---------|
| **飞书配对** | 配对、pairing、不回复 | `飞书配对-真正的解决方案.md` |
| **模型错误** | Unknown model | `模型Unknown问题-解决方案.md` |
| **实例启动** | 启动失败、端口占用 | （待补充） |
| **配置问题** | 配置错误、格式错误 | （待补充） |

---

### 步骤 2: 快速搜索

```bash
# 在经验库中搜索关键词
cd docs/经验积累
grep -r "配对" . | head -20

# 或使用 rg（更快）
rg "配对" docs/经验积累/
```

---

### 步骤 3: 阅读完整文档

找到相关文档后：
1. **完整阅读**整个文档
2. **理解根本原因**，不要只看解决步骤
3. **对照源码位置**，确认理解正确

---

## ⚠️ 常见错误

### 错误 1: 不查经验库就动手

**现象**: 凭记忆或猜测处理问题

**后果**:
- 重复之前的错误
- 浪费大量时间
- 问题陷入循环

**正确做法**:
```bash
# 第一步：查经验库
cat docs/经验积累/README.md
grep -r "问题关键词" docs/经验积累/

# 第二步：阅读相关文档
cat docs/经验积累/相关文档.md

# 第三步：按文档操作
```

---

### 错误 2: 只看步骤不看原理

**现象**: 只复制粘贴命令，不理解为什么

**后果**:
- 遇到变化就不会处理
- 无法举一反三
- 问题变种时又卡住

**正确做法**:
- 阅读"根本原因"部分
- 理解源码逻辑
- 知其然也知其所以然

---

### 错误 3: 不更新经验库

**现象**: 解决问题后不记录，下次又忘

**后果**:
- 经验无法积累
- 每次都从头开始
- 团队无法共享知识

**正确做法**:
- 解决问题后立即记录
- 包含：问题、原因、解决方案、预防措施
- 更新经验库索引

## 📖 如何使用经验库

### 场景 1: 用户报告问题

```
用户: "飞书bot不回复了"

你的步骤：
1. ✅ 先查: cat docs/经验积累/README.md
2. ✅ 找到: "飞书配对-真正的解决方案.md"
3. ✅ 阅读: 理解 allowFrom 机制
4. ✅ 执行: 按文档步骤操作
5. ✅ 验证: 问题解决

❌ 不要: 直接猜测是配对问题，然后乱改 paired.json
```

---

### 场景 2: 遇到新问题

```
问题: 实例启动失败

步骤：
1. 查经验库：grep -r "启动" docs/经验积累/
2. 如果找到 → 按文档处理
3. 如果没有 → 排查并记录新经验
```

---

### 场景 3: 实现新功能

```
任务: 创建新的自动化脚本

步骤：
1. 查经验库：看是否有类似脚本
2. 阅读项目规范：README.md（Python 3.8+，跨平台）
3. 参考现有脚本：scripts/health_check.py
4. 实现并测试
5. 记录到经验库
```
