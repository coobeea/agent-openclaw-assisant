## 🔧 在脚本中使用

### instance_manager.py 中配置镜像

```python
# skills/openclaw-manager/scripts/instance_manager.py

# 配置 OpenClaw 仓库地址
OPENCLAW_REPO_GITHUB = "https://github.com/openclaw/openclaw.git"
OPENCLAW_REPO_GITEE = "https://gitee.com/618lf/openclaw.git"  # 国内镜像

def install_openclaw(use_mirror=True):
    """
    安装 OpenClaw
    
    Args:
        use_mirror: 是否使用国内镜像（默认 True）
    """
    repo_url = OPENCLAW_REPO_GITEE if use_mirror else OPENCLAW_REPO_GITHUB
    
    print(f"正在从 {repo_url} 克隆...")
    subprocess.run(['git', 'clone', repo_url, 'openclaw'], check=True)
```

## 💡 自动选择策略

### 推荐做法

```bash

if git clone https://gitee.com/618lf/openclaw.git openclaw 2>/dev/null; then
```

### Python 实现

```python
def clone_openclaw_with_fallback(target_dir="openclaw"):
    """
    智能克隆 OpenClaw（自动切换镜像）
    """
    # 优先使用国内镜像
    mirrors = [
        ("Gitee 国内镜像", "https://gitee.com/618lf/openclaw.git"),
        ("GitHub 官方", "https://github.com/openclaw/openclaw.git"),
    ]
    
    for name, url in mirrors:
        try:
            print(f"正在尝试 {name}: {url}")
            subprocess.run(
                ['git', 'clone', url, target_dir],
                check=True,
                timeout=60
            )
            print(f"✅ 使用 {name} 成功")
            return True
        except Exception as e:
            print(f"❌ {name} 失败: {e}")
            continue
    
    raise Exception("所有镜像都失败了")
```

### Q2: 已经用 GitHub 克隆了，如何切换？

**A**: 修改远程仓库地址

```bash
cd openclaw

# 查看当前远程地址
git remote -v

# 切换到 Gitee 镜像
git remote set-url origin https://gitee.com/618lf/openclaw.git

# 验证
git remote -v
```

---

### Q3: 两个地址可以混用吗？

**A**: 可以，添加多个远程仓库

```bash
cd openclaw

# 保留 GitHub
git remote rename origin github

# 添加 Gitee 镜像
git remote add gitee https://gitee.com/618lf/openclaw.git

# 从 Gitee 拉取（国内快）
git pull gitee main

# 推送到 GitHub（如果有权限）
git push github main
```
