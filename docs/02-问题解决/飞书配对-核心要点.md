# 🎯 飞书配对 - 核心要点

> **经验来源**: 2026-03-11 实际问题排查  
> **重要程度**: ⭐⭐⭐⭐  
> **必须记住**: 配对 = 批准 + **重启**

---

## ⚠️ 最关键的一点

### 配对后必须重启实例！

```
批准配对 ✅
    ↓
⚠️ 重启实例（必须！）
    ↓
配对生效 ✅
```

**不重启 = 配对不生效 = 问题看起来"修复了但还是不行"**

---

## 🔧 标准流程

### 步骤 1: 发现配对请求

**症状**: 飞书机器人不回复

**检查日志**:
```bash
tail -50 workspace/logs/{name}.log | grep "pairing request"
```

**如果看到**:
```
[feishu] pairing request sender=ou_xxx
```

说明需要配对。

---

### 步骤 2: 查看配对信息

```bash
cat workspace/lobsters/{name}/credentials/feishu-pairing.json
```

**记录**:
- 配对码（如 `CHVPDPUJ`）
- 用户名
- 用户ID

---

### 步骤 3: 批准配对

**使用自动化脚本（推荐）**:
```bash
./scripts/approve_feishu_pairing.sh {instance-name}
```

这个脚本会自动：
1. 读取配对请求
2. 批准配对
3. **自动重启实例**

**或手动批准**:
1. 运行批准脚本
2. **手动重启实例**

---

### 步骤 4: 验证

在飞书里发送测试消息：
```
你好
```

应该能正常收到回复。

---

## 🚨 常见错误

### 错误 1: 批准后不重启

**现象**: 批准了配对，但机器人还是要求配对

**原因**: 没有重启实例

**解决**: 
```bash
python3 skills/openclaw-manager/scripts/instance_manager.py restart {name}
```

---

### 错误 2: 使用过期的配对码

**现象**: 配对码对不上

**原因**: 每次重启后，配对码会更新

**解决**: 总是查看最新的 `feishu-pairing.json`

---

### 错误 3: 多次尝试被去重

**现象**: 发送消息后没反应

**原因**: 消息被去重机制过滤

**解决**:
```bash
# 清空去重缓存
rm -f workspace/lobsters/{name}/feishu/dedup/default.json

# 重启实例
python3 skills/openclaw-manager/scripts/instance_manager.py restart {name}
```

---

## 🛠️ 快速命令

### 一键批准配对

```bash
python3 scripts/approve_feishu_pairing.py openclaw-feishu-2774
```

### 查看配对状态

```bash
# 查看待配对
cat workspace/lobsters/{name}/credentials/feishu-pairing.json

# 查看已配对
cat workspace/lobsters/{name}/devices/paired.json | grep feishu

# 健康检查（包含配对状态）
python3 scripts/health_check.py
```

### 清理并重新配对

```bash
# 1. 清空配对请求
echo '{"version":1,"requests":[]}' > workspace/lobsters/{name}/credentials/feishu-pairing.json

# 2. 清空去重缓存
rm -f workspace/lobsters/{name}/feishu/dedup/default.json

# 3. 重启
python3 skills/openclaw-manager/scripts/instance_manager.py restart {name}

# 4. 在飞书里重新发消息
```
