## 💡 经验积累原则

### 1. 及时记录

**原则**: 
> 遇到问题，立即记录，不要拖延

**流程**:
- 问题出现 → 立即创建文档
- 问题解决 → 立即补充方案
- 提取经验 → 立即更新索引

### 2. 标准格式

**统一结构**:
1. 问题现象
2. 根本原因
3. 完整解决方案
4. 常见错误
5. 快速命令
6. 核心要点（一句话）

### 3. 工具配套

**每个经验都要有**:
- 📝 详细文档
- 🛠️ 自动化脚本
- 🔍 健康检查集成
- 📚 知识库索引

### 4. 持续改进

**不断优化**:
- 简化操作步骤
- 提高自动化程度
- 完善文档说明
- 增强工具功能
