## 📋 实施内容

### 1. ✅ 自动化创建流程

**文件**: `skills/openclaw-manager/scripts/instance_manager.py`

**新增方法**: `_sync_models_config()`

**功能**:
- 从 `workspace/data/models.json` 自动读取全局模型配置
- 自动同步到新创建实例的 `.openclaw/openclaw.json`
- 确保 `models.providers` 配置完整
- 自动填充 `agents.defaults.models` 可用模型列表

**集成点**: `create()` 方法第 6.5 步

```python
# 6.5. 自动同步完整的模型配置（预防 "Unknown model" 问题）
print(f"\n⏳ 同步模型配置...")
if self._sync_models_config(instance_path):
    print(f"✅ 模型配置已同步")
else:
    print(f"⚠️  模型配置同步失败，可能影响 AI 功能")
```

**效果**: 
- 🎯 新创建的龙虾实例 **自动** 拥有完整的模型配置
- 🎯 不再需要手动编辑配置文件
- 🎯 从源头避免 "Unknown model" 问题

### 3. ✅ 健康检查脚本

**文件**: `scripts/health_check.py`

**检查项目**:
1. **命名规范检查**
   - 无中文字符
   - 全小写
   - `openclaw-` 前缀
   - 无非法字符

2. **模型配置检查**
   - `models` 字段存在
   - `models.providers` 存在
   - `models.providers.bailian` 配置完整
   - 必需字段: `baseUrl`, `apiKey`, `api`, `models`
   - `bailian.models` 格式和内容

3. **问题分级**
   - 🔴 `critical`: 严重问题（如模型配置缺失）
   - ⚠️  `warning`: 警告（如命名不规范）

**使用方法**:
```bash
python3 scripts/health_check.py
```

**示例输出**:

**效果**:
