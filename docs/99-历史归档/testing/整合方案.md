## 🔀 方案选择

### 方案 A: 完全整合（推荐）

**描述**: 将新的技能包作为现有系统的增强版本

**实施步骤**:
1. 将新项目的 `skills/` 目录复制到 `agent-openclaws/` 项目
2. 更新技能包脚本，使用与现有 lobster-manager 相同的实现方式
3. 保留现有的数据结构和工具
4. 添加 `AGENTS.md` 到现有项目，提供智能入口

**优势**:
- ✅ 数据统一，无需同步
- ✅ 工具统一，无需维护两套
- ✅ 用户只需关注一个项目

**劣势**:
- ⚠️ 需要大量重构现有代码
- ⚠️ 可能影响现有系统稳定性

### 方案 B: 独立并存

**描述**: 新项目作为独立的技能包平台，与现有系统并存

**实施步骤**:
1. 在新项目中创建独立的数据目录
2. 技能包脚本调用相同的 OpenClaw CLI
3. 两个项目可以管理不同的龙虾集合
4. 通过配置文件控制使用哪个系统

**优势**:
- ✅ 互不影响，风险低
- ✅ 可以逐步迁移
- ✅ 保留现有系统作为备份

**劣势**:
- ⚠️ 需要维护两套系统
- ⚠️ 数据可能不一致
- ⚠️ 用户需要选择使用哪个

### 方案 C: 渐进式迁移（平衡）

**描述**: 先独立开发和测试，验证后逐步迁移

**实施步骤**:
1. **第一阶段（当前）**: 在新项目中独立开发和测试
   - 创建测试专用的数据目录
   - 验证所有功能
   - 完善文档和测试

2. **第二阶段**: 软链接数据，实现共享
   - 在新项目中创建软链接指向现有数据
   - 两个系统使用相同的数据
   - 继续测试确保兼容性

3. **第三阶段**: 合并或保留
   - 根据测试结果决定：
     - 如果新系统更好：迁移到新系统
     - 如果两者各有优势：保留两套
     - 如果现有系统更稳定：废弃新系统

**优势**:
- ✅ 风险可控，分阶段进行
- ✅ 可以在不影响现有系统的情况下验证新功能
- ✅ 最终方案灵活，可以根据实际情况调整

**劣势**:
- ⚠️ 需要更多时间
- ⚠️ 短期内需要维护两套

### OpenClaw CLI 调用封装

创建 `skills/openclaw-manager/scripts/openclaw_cli.py`:

```python
import subprocess
import os
from pathlib import Path
from typing import Dict, List, Optional
from .config import OPENCLAW_CLI

def run_openclaw(
    args: List[str],
    workspace_dir: Optional[Path] = None,
    config_file: Optional[Path] = None,
    state_dir: Optional[Path] = None,
    capture_output: bool = True,
    timeout: Optional[int] = None
) -> subprocess.CompletedProcess:
    """
    运行 OpenClaw CLI 命令
    
    Args:
        args: OpenClaw 命令参数
        workspace_dir: 工作目录
        config_file: 配置文件路径（设置 OPENCLAW_CONFIG_PATH）
        state_dir: 状态目录（设置 OPENCLAW_STATE_DIR）
        capture_output: 是否捕获输出
        timeout: 超时时间（秒）
    
    Returns:
        subprocess.CompletedProcess 对象
    """
    env = os.environ.copy()
    
    if config_file:
        env['OPENCLAW_CONFIG_PATH'] = str(config_file)
    
    if state_dir:
        env['OPENCLAW_STATE_DIR'] = str(state_dir)
    
    cmd = ['node', str(OPENCLAW_CLI)] + args
    
    return subprocess.run(
        cmd,
        env=env,
        cwd=str(workspace_dir) if workspace_dir else None,
        capture_output=capture_output,
        text=True,
        timeout=timeout
    )
```

### 迁移现有 lobster-manager 工具的最佳实践

参考用户现有的 `create-lobster.py`，我们学到：

1. **使用 OpenClaw CLI 初始化工作区**:
   ```python
   run_openclaw(['setup', '--workspace', str(workspace_dir)], env_overrides=env)
   ```

2. **使用 `openclaw config set` 设置配置**:
   ```python
   run_openclaw(['config', 'set', 'gateway.auth.token', token], env_overrides=env)
   run_openclaw(['config', 'set', 'gateway.mode', 'local'], env_overrides=env)
   ```

3. **验证配置**:
   ```python
   verify_result = run_openclaw(['config', 'validate'], env_overrides=env)
   ```

4. **环境变量隔离**:
   ```python
   env = {
       'OPENCLAW_STATE_DIR': str(openclaw_dir),
       'OPENCLAW_CONFIG_PATH': str(openclaw_dir / 'openclaw.json')
   }
   ```
