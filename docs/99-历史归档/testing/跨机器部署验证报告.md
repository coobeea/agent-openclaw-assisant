## 🎯 核心特性

### 1. 智能路径检测

**OpenClaw CLI 检测顺序**:
1. 环境变量 `OPENCLAW_CLI_PATH`（优先级最高）
2. 全局命令 `openclaw`（`which openclaw`）
3. 项目相邻目录 `../openclaw/dist/index.js`
4. Home 目录 `~/git/git_agents/openclaw/dist/index.js`
5. Home 目录 `~/openclaw/dist/index.js`

**好处**:
- ✅ 用户无需配置，自动找到 OpenClaw
- ✅ 支持多种安装方式
- ✅ 找不到时有友好提示

### 2. 灵活的配置方式

**配置优先级**（从高到低）:
```
命令行参数 > 环境变量 > .env 文件 > 默认值
```

**配置方法**:
1. **环境变量**:
   ```bash
   export OPENCLAW_CLI_PATH=/path/to/openclaw
   ```

2. **.env 文件**:
   ```bash
   echo "OPENCLAW_CLI_PATH=/path/to/openclaw" > .env
   ```

3. **默认值**:
   ```python
   # 自动检测，无需配置
   ```

### 3. 自动路径计算

**项目根目录**:
```python
# 相对于 config.py 文件自动计算
PROJECT_ROOT = Path(__file__).resolve().parent.parent.parent.parent
```

**工作空间**:
```python
# 默认在项目根目录下
WORKSPACE_ROOT = PROJECT_ROOT / 'test-workspace'

# 或从环境变量读取（支持相对和绝对路径）
WORKSPACE_ROOT = Path(os.getenv('OPENCLAW_ASSISTANT_WORKSPACE', ...))
```

### 4. 跨平台兼容

**技术实现**:
- ✅ 使用 `pathlib.Path`（自动处理路径分隔符）
- ✅ 使用 `shutil.which`（跨平台命令查找）
