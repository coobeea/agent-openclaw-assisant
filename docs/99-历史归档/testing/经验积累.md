## 🎓 OpenClaw 项目理解

### 项目基本信息

- **项目地址**: https://github.com/openclaw/openclaw
- **主要语言**: Node.js / TypeScript
- **运行要求**: Node.js >= 22.12.0
- **包管理器**: pnpm (推荐), npm, bun
- **核心功能**: 多渠道 AI 网关（支持 WhatsApp, Telegram, Slack, Discord, Feishu 等）
- **安装方式**: `npm install -g openclaw@latest` 或从源码构建
- **配置方式**: `openclaw config set <key> <value>` 或直接编辑 `openclaw.json`
- **部署方式**: Process 模式（systemd/launchd）或 Docker 容器

### 项目结构理解

1. **OpenClaw CLI** (`openclaw` 命令):
   - `openclaw onboard` - 引导式设置
   - `openclaw gateway` - 启动网关
   - `openclaw agents list/add/delete` - 管理智能体
   - `openclaw config set/get/validate` - 配置管理
   - `openclaw message send` - 发送消息

2. **工作空间结构**:
   ```
   workspace/
   ├── .openclaw/
   │   ├── openclaw.json     # 配置文件
   │   ├── identity/         # 设备标识
   │   └── workspace-<id>/   # 智能体工作区
   ```

3. **"龙虾"概念**:
   - **龙虾 = OpenClaw Gateway 实例**
   - 每个龙虾有独立的工作空间和配置
   - 通过环境变量隔离：`OPENCLAW_CONFIG_PATH`, `OPENCLAW_STATE_DIR`
   - 可以在一台机器上运行多个龙虾（不同端口）

### 关键发现

1. **配置文件格式**（2026-03-10）:
   - `models.json`: 模型配置，包含 providers 和每个 provider 的 models
   - `channels.jsonl`: 渠道配置，每行一个 JSON 对象
   - `agents.jsonl`: 智能体配置，每行一个 JSON 对象（这是用户自定义的管理数据库）
   
2. **真实数据观察**（2026-03-10）:
   - 模型配置中，bailian provider 已启用，有真实 API Key
   - 渠道配置中，有飞书渠道（app_id, app_secret）
   - 智能体配置中，有 3 个实例，1 个正在运行（PID: 11763）
   - 工作空间路径格式: `/path/openclaw-workspace/lobsters/lobster-{random}-{hash}`

3. **用户现有系统**（2026-03-10）:
   - 用户在 `/path/to/agent-openclaws/` 已有完整的 lobster-manager 系统
   - 包含 27 个 Python 管理工具（create-lobster.py, start-lobster.py, etc.）
   - 有真实的配置数据和运行中的龙虾实例
   - 使用自定义的 `agents.jsonl` 数据库管理多个龙虾

4. **Lobster vs Agent**（重要区分！）（2026-03-10）:
   - **Lobster（工作流）**: OpenClaw 的一个插件，用于定义工作流（类似 GitHub Actions）
   - **Agent（智能体）**: OpenClaw 中的 AI 对话实体，通过 `openclaw agents` 管理
   - **"龙虾"（用户术语）**: 用户对整个 OpenClaw Gateway 实例的称呼
   - 混淆点：用户的 `agents.jsonl` 实际记录的是"龙虾实例"，不是 OpenClaw 的 agents

5. **配置管理方式**（2026-03-10）:
   - OpenClaw 官方方式：`openclaw config set` 命令
   - 用户的 lobster-manager：通过 Python 脚本调用 OpenClaw CLI
   - 配置验证：`openclaw config validate`

6. **多实例管理**（2026-03-10）:
   - 通过环境变量实现多实例：
     ```bash
     OPENCLAW_CONFIG_PATH=/path/to/lobster1/.openclaw/openclaw.json \
     OPENCLAW_STATE_DIR=/path/to/lobster1/.openclaw \
     openclaw gateway --port 18800
     ```
   - 每个龙虾独立运行，互不干扰
   - PID 记录在 `.openclaw/.pid` 文件中
