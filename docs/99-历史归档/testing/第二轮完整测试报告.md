## 🔍 发现的问题

### 问题 1: Token 获取方式不明确 ℹ️

**描述**: 
- `device.json` 在首次用户访问时生成
- 测试脚本无法自动获取

**影响**: 
- 无法生成完整的访问 URL
- 需要用户手动访问 Web UI

**优先级**: P2（不影响核心功能）

**解决方案**:
1. 短期：在测试报告中说明（用户手动访问）
2. 中期：研究 OpenClaw 是否有API获取Token
3. 长期：考虑在启动时输出访问URL（如果OpenClaw支持）

---

### 问题 2: 日志重定向未实现 ℹ️

**描述**:
- 后台进程的 stdout/stderr 未保存到文件
- 无法查看启动过程的详细日志

**影响**:
- 调试时不便
- 无法追溯启动问题

**优先级**: P1（影响调试）

**解决方案**:
```python
# 启动时重定向日志
log_file = workspace / 'gateway.log'
with open(log_file, 'w') as f:
    process = subprocess.Popen(
        cmd,
        stdout=f,
        stderr=subprocess.STDOUT,
        ...
    )
```
