## 🔍 发现的问题

### 问题 1: 配置文件格式不兼容 ⚠️

**描述**:
用户提供的 `models.json` 包含 OpenClaw 不认识的字段（`id`, `name`, `enabled` 在 provider 级别）

**影响**: 导致 OpenClaw 启动失败

**解决**: 清理配置文件，只保留 OpenClaw 支持的字段

**根本原因**: 配置文件可能来自其他工具或旧版本

**建议**: 添加配置验证脚本，参考知识库自动修复

### 问题 2: Device Token 获取方式不明确 ℹ️

**描述**:
`device.json` 在首次访问时生成，测试脚本无法自动获取

**影响**: 无法自动生成完整的访问 URL

**解决方案**:
1. 手动运行 `openclaw onboard`（需要交互）
2. 访问 Web UI 后，Token 会生成
3. 或从日志中提取 URL（如果 OpenClaw 输出）

**建议**: 研究 OpenClaw CLI 是否有非交互方式获取 Token
