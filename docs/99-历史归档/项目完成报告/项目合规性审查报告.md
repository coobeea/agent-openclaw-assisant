## ❌ 严重不符合项（P0）

### 问题 1: 工作空间配置未按需求实现 ⚠️⚠️⚠️

**原始需求**（docs/需求分析.md 173-186行）:
> 工作空间路径通过 `global.yaml` 配置，不硬编码。

**现状问题**:

#### 1.1 config.py 未读取 global.yaml

```python
# skills/openclaw-manager/scripts/config.py 第53-56行
WORKSPACE_ROOT = Path(os.getenv(
    'OPENCLAW_ASSISTANT_WORKSPACE',
    str(PROJECT_ROOT / 'test-workspace')  # ❌ 硬编码默认值
))
```

**应该**: 优先从 `shared/configs/global.yaml` 读取

#### 1.2 OpenClawUtils 使用硬编码路径

```python
# shared/utils/common.py 第16-17行
def __init__(self, workspace_root: str = "./workspace"):  # ❌ 硬编码
    self.workspace_root = Path(workspace_root)
```

**应该**: 从 `get_global_config()` 读取 `workspace_root`

#### 1.3 多处配置不统一

| 组件 | 工作空间路径 | 数据目录 |
|------|-------------|----------|
| instance_manager.py | `./workspace` | 无 |
| e2e_test_create_lobster.py | `test-workspace/lobsters` | `test-workspace/data` |
| shared/utils/common.py | `./workspace` | 无 |

**问题**: 3套配置逻辑，互不兼容

**影响**:
- ❌ 无法跨机器部署（路径硬编码）
- ❌ 实例管理器创建的实例找不到（路径不一致）
- ❌ 不符合原始需求的核心原则

**修复优先级**: **P0 - 阻塞性问题**

### 问题 2: instance_manager.py 使用错误的 OpenClaw 命令 ⚠️⚠️⚠️

**现状**（skills/openclaw-manager/scripts/instance_manager.py）:


- ❌ 启动实例失败（命令不存在）
