## 🎯 核心设计原则（已落实）

### 1. 工作空间保真设计 ⭐

✅ **不预定义内部结构**: 工作空间的内部目录（config/, data/, logs/, plugins/）完全由 OpenClaw 自己管理，技能包不做任何假设。

✅ **路径可配置**: 工作空间根路径通过 `shared/configs/global.yaml` 配置，支持相对路径、绝对路径、用户主目录。

✅ **CLI 交互**: 所有操作通过 OpenClaw CLI 进行，不直接修改内部文件。

### 2. 隐私保护

✅ **严格 .gitignore**: 工作空间、日志、凭证、临时文件全部排除。

✅ **凭证加密**: 所有敏感信息（API Key、App Secret）使用 Fernet 加密存储。

✅ **密钥管理**: 加密密钥存储在 `workspace/.keyfile`，权限 600。

### 3. Cursor 技能包规范

✅ **标准格式**: 每个技能包包含 `SKILL.md`、`reference/`、`scripts/`、`templates/`。

✅ **YAML Frontmatter**: SKILL.md 包含 name 和 description。

✅ **渐进式文档**: 使用 reference/ 目录实现文档的渐进披露。

✅ **可执行脚本**: 所有脚本添加执行权限。

### 4. 统一命名规范

✅ **实例命名**: `openclaw-{env}-{number}` 格式。

✅ **智能体命名**: `{instance}-agent-{name}` 格式。

✅ **统一英文前缀**: 所有资源使用英文命名。

## 🚀 使用方式

### Cursor 中使用

在 Cursor IDE 中直接与 AI 对话：

```
"帮我安装 OpenClaw"
"创建一个实例叫 openclaw-prod-01"
"部署到 Docker"
"给实例安装飞书插件"
"添加 gpt-4 模型"
"创建一个客服智能体"
```

Cursor AI 会自动识别并使用对应的技能包。

### 命令行使用

所有工具也可以独立使用：

```bash
# 安装 OpenClaw
bash skills/openclaw-manager/scripts/install_openclaw.sh

# 创建实例
python skills/openclaw-manager/scripts/instance_manager.py create openclaw-prod-01

# 部署到 Docker
bash skills/openclaw-deploy/scripts/deploy_docker.sh openclaw-prod-01

# 安装插件
python skills/openclaw-plugin/scripts/plugin_manager.py install feishu --instance openclaw-prod-01

# 添加渠道
python skills/openclaw-channel/scripts/channel_manager.py add \
  --instance openclaw-prod-01 \
  --platform feishu \
  --app-id xxx \
  --app-secret xxx

# 添加模型
python skills/openclaw-model/scripts/model_manager.py add \
  --instance openclaw-prod-01 \
  --model gpt-4 \
  --provider openai \
  --api-key sk-xxx

# 创建智能体
python skills/openclaw-agent/scripts/agent_manager.py create \
  --instance openclaw-prod-01 \
  --name customer-service
```

## 🎓 关键技术决策

### 决策 1: 采用软链接激活

**原因**: 
- Cursor 识别 `.cursor/skills/`
- 版本控制友好（只提交源文件）
- 开发便利（修改源文件即时生效）

### 决策 2: 工作空间保真设计

**原因**:
- OpenClaw 可能更新内部结构
- 避免假设导致的兼容性问题
- 更灵活、更可维护

### 决策 3: CLI 优先

**原因**:
- OpenClaw 提供命令行工具
- CLI 更稳定（相比直接修改配置文件）
- 适应 OpenClaw 版本更新

### 决策 4: 凭证加密存储

**原因**:
- 保护敏感信息（API Key、App Secret）
- 使用 Fernet（对称加密，安全高效）
- 密钥文件权限 600
