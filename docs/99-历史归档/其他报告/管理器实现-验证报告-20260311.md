## 🐛 Bug修复

### KeyError: 'running'

**问题**: orchestrator.py 访问不存在的 `status['running']` 字段

**原因**: instance_manager.status() 返回的是完整的 instance_info 字典，没有 'running' 字段

**修复**: 改为直接检查 `process_pid` 和使用 `psutil.pid_exists()`

**代码**:
```python
# ❌ 错误
if status and status['running']:

# ✅ 正确  
pid = inst.get('process_pid')
is_running = psutil.pid_exists(pid) if pid else False
```
