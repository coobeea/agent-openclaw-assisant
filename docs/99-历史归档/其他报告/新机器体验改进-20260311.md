## 🔧 技术实现

### 模板文件结构

```json
{
  "name": "模板名称",
  "description": "模板描述",
  "provider": "bailian",
  "baseUrl": "https://api-endpoint.com/v1",
  "api": "openai-completions",
  "models": [
    {
      "id": "model-id",
      "name": "显示名称 (推荐)",
      "reasoning": false,
      "input": ["text", "image"],
      "cost": {...},
      "contextWindow": 1000000,
      "maxTokens": 65536,
      "description": "模型描述"
    }
  ]
}
```

### 初始化流程

```python
def init_from_template(template_name, api_key, instance_name):
    # 1. 读取模板文件
    template = load_template(template_name)
    
    # 2. 更新全局配置
    update_global_config(template, api_key)
    
    # 3. 更新实例配置（如果指定）
    if instance_name:
        update_instance_config(instance_name, template, api_key)
    
    # 4. 设置默认模型
    set_default_model(template.models[0])
    
    # 5. 完成报告
    print("✅ 初始化完成")
```
