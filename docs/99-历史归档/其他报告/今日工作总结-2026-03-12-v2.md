## 🎓 核心经验

### 经验 1: 首屏响应的重要性

**核心发现**:
- 用户说"你好"不是礼貌，是**迷茫**
- 第一印象决定是否继续使用
- 主动引导比被动等待有效 10 倍

**设计原则**:
1. ✅ 主动展示功能（不要反问）
2. ✅ 给出具体示例（不要抽象描述）
3. ✅ 降低心理门槛（鼓励尝试）
4. ✅ 拉回中轴线（引导到核心功能）

**适用场景**:
- 用户说"你好"
- 用户问"能做什么"
- 首次对话
- 任何开放性、模糊的问候

---

### 经验 2: 多平台架构设计

**核心发现**:
- 软链接优于复制（单一数据源）
- 平台特定目录 + 通用源文件 = 最佳实践
- 统一文档结构降低学习成本

**设计原则**:
1. ✅ 单一数据源（源文件在 `skills/`）
2. ✅ 软链接共享（各平台通过软链接访问）
3. ✅ 统一结构（所有平台 README 结构一致）
4. ✅ 自动同步（修改源文件，所有平台立即生效）

**架构优势**:
- 修改一次，所有平台生效
- 永远保持一致
- 易于扩展新平台
