## 故障排除

### 软链接失效

**症状**: `ls -la .cursor/skills/` 显示红色（链接失效）

**解决**:
```bash
cd .cursor/skills
rm openclaw-manager
ln -s ../../skills/openclaw-manager openclaw-manager
```

### Cursor 未识别技能包

**症状**: Cursor AI 不响应技能包相关指令

**解决**:
1. 重启 Cursor
2. 检查 `.cursor/skills/` 目录是否存在
3. 验证 SKILL.md 格式是否正确

### 脚本无执行权限

**症状**: 执行脚本时报 "Permission denied"

**解决**:
```bash
chmod +x skills/openclaw-manager/scripts/*.py
chmod +x skills/openclaw-manager/scripts/*.sh
```
