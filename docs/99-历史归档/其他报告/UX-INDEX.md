## 🎭 核心概念

### 1. 用户说人话，AI 做技术活

**理念**: 用户不需要学习技术术语，用日常语言即可。

**示例**:
```
用户: "搞个飞书机器人"
AI: （自动执行技术步骤）
```

**详见**: [用户体验设计规范 - 1.1节](./用户体验设计规范.md#11-用户说人话ai-做技术活)

---

### 2. 宽泛问题 → 精准引导

**理念**: 用户的问题可能很宽泛，AI 要主动引导到具体操作。

**示例**:
```
用户: "配置一下"
AI: "请问你想配置什么？
     1. 消息平台
     2. AI模型
     ..."
```

**详见**: [用户体验设计规范 - 1.2节](./用户体验设计规范.md#12-宽泛问题--精准引导)

---

### 3. 主动提示下一步

**理念**: 每个操作完成后，主动告诉用户"接下来可以做什么"。

**示例**:
```
✅ 实例创建成功！

🎯 接下来你可以:
   1. "配置飞书渠道"
   2. "发送测试消息"
   ...
```

**详见**: [用户体验设计规范 - 1.3节](./用户体验设计规范.md#13-主动提示下一步)

---

### 4. 智能推荐，减少选择

**理念**: 能自动决策的就不问用户，必须问时提供推荐。

**示例**:
```
AI: "客服场景推荐 GPT-3.5（快速+经济）
     
     你的机器人用来做客服，我推荐 GPT-3.5。
     要改用 GPT-4 吗？"
```

**详见**: [用户体验设计规范 - 1.4节](./用户体验设计规范.md#14-智能推荐减少选择)

---

### 5. 容错优先

**理念**: 用户说错、说得不专业，AI 也能理解。

**示例**:
```
"搞个机器人" = "创建实例" ✅
"用飞书" = "飞书集成" ✅
"配置" = 询问详情 ✅
```

**详见**: [用户体验设计规范 - 1.5节](./用户体验设计规范.md#15-容错优先)

## 🎯 持续改进

### 优化原则

1. **降低门槛** - 让操作更简单
2. **增强容错** - 让错误更容易处理
3. **主动引导** - 让用户不迷失
4. **智能推荐** - 让选择更容易
5. **友好反馈** - 让结果更清晰

### 关注指标

- 首次成功率
- 平均完成时间
- 错误发生率
- 用户满意度

### 反馈渠道

- 用户反馈
- 测试数据
- 使用日志
- 定期review
