# 首屏响应优化

> 2026-03-12 添加首屏主动引导功能

---

## 🎯 问题发现

### 用户反馈

**场景**：用户在 Cursor 中说"你好"

**当前响应**：
```
🤖 AI: "你好！我是OpenClaw管理助手。"
🤖 AI: "我可以帮你：
       • 实例管理
       • 渠道配置
       • 模型配置
       你想做什么呢？"
```

**问题**：
- ❌ 太简单，没有实际帮助
- ❌ 用户看了不知道能做什么
- ❌ 没有给出具体示例
- ❌ 用户仍然困惑

**用户心理**：
```
用户: "你好"
AI: "你好，有什么可以帮助你？"
用户: 😕 还是不知道能做什么...
用户: *关闭对话*
```

---

## ✅ 解决方案

### 添加"首屏响应规则"

在 `AGENTS.md` 最开始添加专门的首屏响应规则：

```markdown
## 🎯 首屏响应规则（最重要！）

### 触发条件
当用户说以下内容时，**主动展示功能清单**：
- "你好" / "hi" / "hello"
- "有什么功能" / "能做什么"
- 首次对话
- 任何开放性、模糊的问候或询问

### 标准响应模板
[详细的功能清单 + 具体示例]
```

---

```
你好！我是 OpenClaw 管理助手。

我可以帮你：

【模型配置】
• 初始化模型（百炼模板）

或者告诉我你想做什么，我会引导你！
```

## 🎯 核心设计理念

### "拉回中轴线"

**什么是中轴线**：
- 用户使用项目的核心功能
- 最常见、最重要的使用场景

**为什么要拉回中轴线**：
- 用户说"你好"是**迷茫**的表现
- 用户不知道能做什么
- 我们要**主动引导**，不要被动等待

**如何拉回中轴线**：
1. ✅ 展示完整功能清单
2. ✅ 给出具体示例对话
3. ✅ 降低心理门槛
4. ✅ 鼓励用户开始尝试

---

## 📋 首屏响应的设计要点

### 1. 功能分类清晰

**❌ 不好的分类**：
```
• 实例管理  ← 太粗，用户不理解
• 渠道配置  ← 什么是渠道？
```

**✅ 好的分类**：
```
【实例管理】
• 创建/启动/停止/重启实例  ← 具体动作
• 查看实例状态和日志      ← 明确说明
```

---

### 2. 必须有示例对话

**❌ 不好的响应**：
```
你想做什么呢？← 用户还是不知道
```

**✅ 好的响应**：
```
你可以直接说：
💬 "创建一个飞书机器人"  ← 具体示例
💬 "查看所有实例"        ← 具体示例
```

---

### 3. 降低心理门槛

**❌ 不好的说法**：
```
请提供以下参数... ← 听起来很复杂
```

**✅ 好的说法**：
```
或者告诉我你想做什么，我会引导你！← 简单，有信心
```

---

### 4. 主动而非被动

**❌ 被动响应**：
```
有什么可以帮助你？← 等待用户说
```

**✅ 主动引导**：
```
我可以帮你：
【功能清单】
你可以说：
【示例对话】← 主动展示
```

## 🎓 设计经验

### 核心原则："拉回中轴线"

**什么是"拉回中轴线"**：
- 用户迷茫时，主动引导到核心功能
- 不让用户自己探索（容易放弃）
- 主动展示能做什么
- 给出具体示例降低门槛

**适用场景**：
- 用户说"你好"
- 用户问"能做什么"
- 首次对话
- 任何模糊、开放性的询问

---

### 用户心理分析

**用户说"你好"的真实含义**：
1. ❓ 不知道这个工具能做什么
2. ❓ 不知道应该怎么说
3. ❓ 想试探一下
4. 😕 感觉迷茫

**AI 应该做什么**：
1. ✅ 主动展示功能清单
2. ✅ 给出具体示例对话
3. ✅ 降低心理门槛
4. ✅ 鼓励用户尝试

**不应该做什么**：
- ❌ 简单回复"你好"
- ❌ 反问"想做什么"
- ❌ 被动等待用户说明需求
- ❌ 让用户自己探索
