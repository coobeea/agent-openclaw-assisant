# ⚠️ 配置文件格式问题

> **严重程度**: ⭐⭐⭐⭐  
> **发生频率**: 高  
> **影响范围**: 实例启动失败  
> **来源**: 端到端测试实际遇到

---

## 🚨 核心问题

**OpenClaw 对配置文件格式有严格要求**，不兼容的字段会导致启动失败。

---

## ❌ 常见错误

### 错误 1: Provider 级别的多余字段

**错误配置**:
```json
{
  "providers": {
    "bailian": {
      "id": "bailian",           // ❌ 不支持
      "name": "百炼",            // ❌ 不支持
      "enabled": true,           // ❌ 不支持
      "baseUrl": "https://...",  // ✅ 支持
      "apiKey": "...",           // ✅ 支持
      "api": "openai-completions", // ✅ 支持
      "models": [...]            // ✅ 支持
    }
  }
}
```

**错误信息**:
```
Config invalid:
- models.providers.bailian: Unrecognized keys: "id", "name", "enabled"
```

**正确配置**:
```json
{
  "providers": {
    "bailian": {
      "baseUrl": "https://coding.dashscope.aliyuncs.com/v1",
      "apiKey": "sk-sp-...",
      "api": "openai-completions",
      "models": [
        {
          "id": "qwen3.5-plus",
          "name": "qwen3.5-plus",
          "reasoning": false,
          "input": ["text", "image"],
          "cost": {"input": 0, "output": 0, "cacheRead": 0, "cacheWrite": 0},
          "contextWindow": 1000000,
          "maxTokens": 65536
        }
      ]
    }
  }
}
```

### 错误 2: 无效的 API 类型

**错误配置**:
```json
{
  "providers": {
    "openai": {
      "api": "openai",  // ❌ 不支持（太简略）
      ...
    }
  }
}
```

**错误信息**:
```
models.providers.openai.api: Invalid option: expected one of 
  "openai-completions"|"openai-responses"|"openai-codex-responses"|
  "anthropic-messages"|"google-generative-ai"|"github-copilot"|
  "bedrock-converse-stream"|"ollama"
```

**正确配置**:
```json
{
  "providers": {
    "openai": {
      "api": "openai-completions",  // ✅ 支持
      ...
    }
  }
}
```

### 错误 3: models 是对象而不是数组

**错误配置**:
```json
{
  "providers": {
    "bailian": {
      ...
      "models": {}  // ❌ 对象
    }
  }
}
```

**正确配置**:
```json
{
  "providers": {
    "bailian": {
      ...
      "models": [   // ✅ 数组
        {
          "id": "qwen3.5-plus",
          "name": "qwen3.5-plus",
          ...
        }
      ]
    }
  }
}
```

## 🔍 支持的字段列表

### Provider 级别（必需字段）

| 字段 | 类型 | 必需 | 说明 |
|-----|------|------|------|
| `baseUrl` | string | ✅ | API 基础 URL |
| `apiKey` | string | ✅ | API 密钥 |
| `api` | string | ✅ | API 类型（见下表） |
| `models` | array | ✅ | 模型列表 |

### Provider 级别（不支持的字段）

| 字段 | 说明 |
|-----|------|
| ❌ `id` | 自定义字段，OpenClaw 不支持 |
| ❌ `name` | 自定义字段，OpenClaw 不支持 |
| ❌ `enabled` | 自定义字段，OpenClaw 不支持 |

### 支持的 API 类型

| API 类型 | 说明 |
|---------|------|
| `openai-completions` | ✅ OpenAI Completions API（推荐） |
| `openai-responses` | ✅ OpenAI Responses API |
| `openai-codex-responses` | ✅ OpenAI Codex API |
| `anthropic-messages` | ✅ Anthropic Messages API |
| `google-generative-ai` | ✅ Google Gemini API |
| `github-copilot` | ✅ GitHub Copilot API |
| `bedrock-converse-stream` | ✅ AWS Bedrock API |
| `ollama` | ✅ Ollama 本地模型 |
| ❌ `openai` | 不支持（太简略） |
| ❌ `openai-compatible` | 不支持 |

### Model 级别（必需字段）

| 字段 | 类型 | 必需 | 说明 |
|-----|------|------|------|
| `id` | string | ✅ | 模型 ID |
| `name` | string | ✅ | 模型名称 |

### Model 级别（可选字段）

| 字段 | 类型 | 说明 |
|-----|------|------|
| `reasoning` | boolean | 是否支持推理模式 |
| `input` | array | 支持的输入类型（text, image等） |
| `cost` | object | 成本信息 |
| `contextWindow` | number | 上下文窗口大小 |
| `maxTokens` | number | 最大输出 token 数 |

## 🛠️ 自动修复脚本

### 清理不支持的字段

```python
#!/usr/bin/env python3
"""
清理 models.json 中不支持的字段
"""
import json
from pathlib import Path

def clean_models_config(input_file: Path, output_file: Path):
    """清理配置文件"""
    with open(input_file, 'r', encoding='utf-8') as f:
        config = json.load(f)
    
    providers = config.get('providers', {})
    
    for provider_name, provider_config in providers.items():
        # 移除不支持的字段
        for key in ['id', 'name', 'enabled']:
            provider_config.pop(key, None)
        
        # 验证 api 字段
        api = provider_config.get('api', '')
        valid_apis = [
            'openai-completions', 'openai-responses', 
            'openai-codex-responses', 'anthropic-messages',
            'google-generative-ai', 'github-copilot',
            'bedrock-converse-stream', 'ollama'
        ]
        
        if api not in valid_apis:
            print(f"⚠️  {provider_name}: 无效的 API 类型 '{api}'")
            # 如果是 'openai'，改为 'openai-completions'
            if api == 'openai':
                provider_config['api'] = 'openai-completions'
                print(f"✅ {provider_name}: 已修正为 'openai-completions'")
        
        # 确保 models 是数组
        models = provider_config.get('models', [])
        if not isinstance(models, list):
            print(f"⚠️  {provider_name}: models 不是数组")
            provider_config['models'] = []
    
    # 写回文件
    with open(output_file, 'w', encoding='utf-8') as f:
        json.dump(config, f, indent=2, ensure_ascii=False)
    
    print(f"✅ 清理完成: {output_file}")

if __name__ == '__main__':
    input_file = Path('models.json')
    output_file = Path('models-clean.json')
    clean_models_config(input_file, output_file)
```

## 🚨 实际案例

### 案例：2026-03-10 端到端测试

**问题**:
使用用户提供的 `models.json` 启动实例失败。

**错误信息**:
```
Config invalid at /path/to/openclaw.json:
- models.providers.dashscope: Unrecognized keys: "id", "name", "enabled"
- models.providers.silicon: Unrecognized keys: "id", "name", "enabled"
- models.providers.openai.api: Invalid option: expected one of "openai-completions"|...
- models.providers.openai: Unrecognized keys: "id", "name", "enabled"
- models.providers.bailian: Unrecognized keys: "id", "name", "enabled"
- models.providers.moonshot: Unrecognized keys: "id", "name", "enabled"
```

**解决**:
1. 清理所有 provider 级别的 `id`, `name`, `enabled` 字段
2. 修正 `openai.api` 从 `"openai"` 到 `"openai-completions"`
3. 只保留 `bailian` provider（其他未使用）

**结果**: ✅ 实例启动成功（PID: 69389）

## 💡 最佳实践

### 1. 使用最小配置

只配置你需要的 provider，不要保留未使用的配置：

```json
{
  "providers": {
    "bailian": {
      // 只配置 bailian
      ...
    }
  }
}
```

### 2. 使用配置验证

启动前验证配置：
```bash
openclaw doctor --fix
```

### 3. 参考官方示例

从 OpenClaw 官方文档获取最新的配置示例。

### 4. 版本兼容性

OpenClaw 可能在版本更新中改变配置格式，注意查看变更日志。
