# 📝 文档编写规范

> 保持项目结构清晰，文档易于查找

---

## 🎯 核心原则

### 原则 1: 根目录整洁

**规则**:
- ✅ 根目录**只能**有这些文件：
  - `README.md` - 项目主README
  - `AGENTS.md` - AI助手配置
  - 配置文件（.gitignore, requirements.txt等）
- ❌ **禁止**在根目录创建任何文档文件

**错误示例**:
```
❌ 快速入门.md
❌ DEPLOYMENT.md
❌ 分析报告.md
❌ 问题解决方案.md
```

**正确做法**:
```
✅ docs/01-使用指南/快速入门.md
✅ docs/04-技术参考/DEPLOYMENT.md
✅ docs/99-历史归档/分析报告.md
✅ docs/02-问题解决/问题解决方案.md
```

---

### 原则 2: 文档分类明确

所有文档必须放在 `docs/` 的对应子目录：

| 文档类型 | 放在哪里 | 示例 |
|---------|---------|------|
| 使用说明 | `docs/01-使用指南/` | 工具链使用指南.md |
| 问题解决 | `docs/02-问题解决/` | 飞书配对-真正的解决方案.md |
| 规范约定 | `docs/03-规范约定/` | 龙虾命名规范.md |
| 技术文档 | `docs/04-技术参考/` | 架构设计.md |
| 历史报告 | `docs/99-历史归档/` | 项目完成报告.md |

---

### 原则 3: 文档命名规范

**格式**: `<主题>-<类型>.md`

**示例**:
- ✅ `飞书配对-真正的解决方案.md`
- ✅ `龙虾命名规范.md`
- ✅ `模型Unknown问题-解决方案.md`

**避免**:
- ❌ `doc1.md`
- ❌ `解决方案.md`（太笼统）
- ❌ `fix.md`（不描述性）

## ⚠️ 常见错误

### 错误 1: 在根目录创建文档

**错误**:
```bash
# 创建了根目录文档
touch 快速入门.md
touch DEPLOYMENT.md
```

**后果**:
- 项目根目录混乱
- 用户不知道哪些是重要文件
- 难以维护

**正确做法**:
```bash
# 放到对应目录
touch docs/01-使用指南/快速入门.md
touch docs/04-技术参考/DEPLOYMENT.md
```

---

### 错误 2: 文档分类不明确

**错误**:
```
docs/
├── 文档1.md
├── 文档2.md
└── 其他/
    └── 文档3.md
```

**后果**:
- 找不到文档
- 不知道文档用途

**正确做法**:
```
docs/
├── 01-使用指南/
│   └── 工具链使用指南.md
├── 02-问题解决/
│   └── 飞书配对-真正的解决方案.md
└── 03-规范约定/
    └── 龙虾命名规范.md
```

---

### 错误 3: 临时文档不归档

**错误**:
```bash
# 写了分析报告放在根目录
touch 分析报告-20260311.md
```

**后果**:
- 根目录越来越乱
- 分不清哪些是当前的，哪些是历史的

**正确做法**:
```bash
# 临时/历史文档放到归档
touch docs/99-历史归档/其他报告/分析报告-20260311.md
```

## ✅ 创建文档的流程

### 步骤 1: 确定文档类型

问自己：
- 这是使用说明？ → `01-使用指南/`
- 这是问题解决？ → `02-问题解决/`
- 这是规范约定？ → `03-规范约定/`
- 这是技术文档？ → `04-技术参考/`
- 这是历史报告？ → `99-历史归档/`

---

### 步骤 2: 选择子目录

根据具体内容，放到对应子目录：

**02-问题解决/** 下：
- 具体问题解决方案
- 故障排查流程
- 经验总结

**99-历史归档/** 下：
- `配置系统统一/` - 配置相关历史
- `项目完成报告/` - 项目报告
- `其他报告/` - 其他临时文档

---

### 步骤 3: 命名文件

使用描述性名称：
- `<问题>-<类型>.md`
- `<主题>-<说明>.md`

---

### 步骤 4: 更新索引

创建文档后，更新对应目录的 `README.md`：

```markdown
## 📚 文档列表

| 文档 | 用途 | 必读 |
|------|------|------|
| [新文档.md](./新文档.md) | 说明 | ⭐⭐⭐ |
```

---
