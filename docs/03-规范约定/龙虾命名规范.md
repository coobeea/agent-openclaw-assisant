## 🎯 核心原则

### ❌ 禁止使用中文

**原因**:
- 文件路径编码问题
- 跨平台兼容性问题
- 某些工具不支持中文
- 可能导致无法恢复的故障

**示例**:
```
❌ 错误: 字叫生产客服001
❌ 错误: 生产客服001
❌ 错误: 飞书机器人
❌ 错误: 客服助手
```

### ✅ 统一前缀

**必须使用**: `openclaw-`

**理由**:
- 清晰标识实例类型
- 便于批量管理
- 避免与其他系统冲突
- 符合行业规范

## 📋 命名格式

### 标准格式

**格式 1: 完整格式（推荐生产环境）**
```
openclaw-{platform}-{env}-{sequence}
```

**格式 2: 简化格式（可用于测试环境）**
```
openclaw-{platform}-{sequence}
```

### 组成部分

| 部分 | 说明 | 是否必需 | 可选值 | 示例 |
|-----|------|---------|-------|------|
| **前缀** | 固定前缀 | ✅ 必需 | `openclaw` | openclaw |
| **平台** | 对接平台 | ✅ 必需 | feishu, qq, wecom, dingtalk, etc | feishu |
| **环境** | 运行环境 | ⚠️ 推荐 | prod, test, dev, staging | prod |
| **序号** | 唯一标识 | ✅ 必需 | 001-999 或 4位随机数 | 001, 4829 |

### 命名验证

```python
import re

def validate_instance_name(name: str) -> bool:
    """
    验证实例名称是否符合规范
    
    规则:
    - 必须以 openclaw- 开头
    - 只能包含小写字母、数字、连字符
    - 不能包含中文或其他特殊字符
    - 格式: openclaw-{platform}-{env}-{seq}
    """
    # 正则表达式
    pattern = r'^openclaw-[a-z0-9]+-[a-z]+-[0-9]{3,4}$'
    
    if not re.match(pattern, name):
        return False
    
    # 检查是否包含中文
    if any('\u4e00' <= char <= '\u9fff' for char in name):
        return False
    
    return True

# 使用示例
validate_instance_name("openclaw-feishu-prod-001")  # ✅ True
validate_instance_name("字叫生产客服001")            # ❌ False
validate_instance_name("生产客服001")                # ❌ False
validate_instance_name("OpenClaw-Feishu-001")       # ❌ False (大写)
```
