## 📋 规范要点总结

### ✅ 必须遵守

1. **前缀统一**: 所有实例必须以 `openclaw-` 开头
2. **纯英文**: 只使用小写字母、数字和连字符
3. **平台标识**: 明确标识对接平台（feishu, qq, wecom等）
4. **唯一序号**: 使用数字序号确保唯一性

### ❌ 严格禁止

1. **中文字符**: 任何中文都不允许
2. **大写字母**: 必须全部小写
3. **特殊符号**: 除连字符外的特殊符号
4. **空格**: 不允许使用空格

### 📐 格式示例

**推荐格式**:
```
✅ openclaw-feishu-prod-001    (完整格式，生产环境)
✅ openclaw-feishu-test-4829   (完整格式，测试环境)
✅ openclaw-feishu-2774        (简化格式)
✅ openclaw-qq-prod-001        (QQ平台)
```

## 🔍 验证工具

### 快速验证脚本

```bash
#!/bin/bash
# 验证龙虾命名是否符合规范

NAME="$1"

# 检查前缀
if [[ ! "$NAME" =~ ^openclaw- ]]; then
    echo "❌ 前缀错误：必须以 openclaw- 开头"
    exit 1
fi

# 检查格式
if [[ "$NAME" =~ ^openclaw-[a-z0-9]+-([a-z]+-)?[0-9]{3,4}$ ]]; then
    echo "✅ 命名符合规范: $NAME"
else
    echo "❌ 格式错误: $NAME"
    exit 1
fi

# 检查中文
if echo "$NAME" | grep -P '[\x{4e00}-\x{9fff}]' > /dev/null; then
    echo "❌ 包含中文字符"
    exit 1
fi

echo "✅ 所有检查通过"
```

**使用方法**:
```bash
./validate_name.sh openclaw-feishu-2774
# 输出: ✅ 所有检查通过

./validate_name.sh 字叫生产客服001
# 输出: ❌ 前缀错误：必须以 openclaw- 开头
```
