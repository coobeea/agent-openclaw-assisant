## 🎯 为什么需要虚拟环境？

### ❌ 不使用虚拟环境的问题

1. **依赖冲突**
   - 不同项目的包版本冲突
   - 系统 Python 环境混乱
   - 难以追踪依赖关系

2. **跨机器不一致**
   - A 机器能运行，B 机器报错
   - 依赖版本不统一
   - 难以复现问题

3. **污染系统环境**
   - 安装过多不必要的包
   - 影响其他项目
   - 难以清理

### ✅ 使用虚拟环境的优势

1. **隔离依赖** - 项目依赖独立，不相互干扰
2. **版本锁定** - 确保所有机器环境一致
3. **易于管理** - 一键创建/删除，不污染系统
4. **可复现性** - 团队成员环境完全一致

## 📐 核心规范

### ✅ 必须遵守的规则

1. **所有 Python 脚本必须在虚拟环境中运行**
   ```bash
   # ✅ 正确方式1: 直接使用虚拟环境Python（推荐，AI助手方式）
   .venv/bin/python skills/openclaw-manager/scripts/instance_manager.py list
   
   # ✅ 正确方式2: 先激活再运行
   source .venv/bin/activate
   python skills/openclaw-manager/scripts/instance_manager.py list
   
   # ❌ 错误方式
   python3 skills/openclaw-manager/scripts/instance_manager.py list
   ```

2. **安装新依赖时必须在虚拟环境中**
   ```bash
   # ✅ 正确方式
   .venv/bin/pip install <package>
   
   # 或激活后安装
   source .venv/bin/activate
   pip install <package>
   
   # ❌ 错误方式
   pip3 install <package>
   ```

3. **新依赖必须添加到 env-checker/requirements.txt**
   ```bash
   # 编辑统一依赖文件
   vim skills/env-checker/requirements.txt
   
   # 添加新依赖
   echo "new-package>=1.0.0" >> skills/env-checker/requirements.txt
   
   # 重新安装
   .venv/bin/pip install -r skills/env-checker/requirements.txt
   ```

## 🚨 故障排查

### 问题 1: 系统没有 Python

**症状**: `python: command not found`

**解决方案**:
```bash
# env-checker 会自动检测和安装！
bash skills/env-checker/scripts/setup.sh

# 它会自动：
# 1. 检测系统Python
# 2. 如果没有，自动下载并安装 Python 3.12.8
# 3. 创建虚拟环境
```

**无需手动安装Python！** 🌟

---

### 问题 2: 虚拟环境创建失败

**症状**: setup.sh 报错

**解决方案**:
```bash
# 检查磁盘空间
df -h

# 检查权限
ls -la .

# 重新尝试（添加 --verbose 查看详细日志）
bash skills/env-checker/scripts/setup.sh --verbose
```

---

### 问题 3: 激活失败

**症状**: `source .venv/bin/activate` 无效

**解决方案**:
```bash
# 检查虚拟环境是否存在
ls -la .venv/bin/activate

# 如果不存在，重新创建
bash skills/env-checker/scripts/setup.sh

# Windows PowerShell 可能需要修改执行策略
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
```

---

### 问题 4: 包导入失败

**症状**: `ModuleNotFoundError: No module named 'xxx'`

**解决方案**:
```bash
# 1. 确认依赖已添加到 env-checker/requirements.txt
cat skills/env-checker/requirements.txt | grep <package>

# 2. 重新安装依赖
.venv/bin/pip install -r skills/env-checker/requirements.txt

# 3. 运行验证
.venv/bin/python skills/env-checker/scripts/verify.py
```

---

### 问题 5: Python 版本不匹配

**症状**: env-checker 报 "Python 版本不符合要求"

**解决方案**:
```bash
# env-checker 会自动安装 Python 3.12！
# 只需重新运行
bash skills/env-checker/scripts/setup.sh

# 它会自动下载并安装正确版本
```
