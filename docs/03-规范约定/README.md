# 📐 规范约定

> 必须遵守的规范，避免犯错

---

## 🎯 核心规范

### 1. 命名规范

**文档**: [龙虾命名规范.md](./龙虾命名规范.md)

**规则**:
- 格式: `openclaw-{platform}-{sequence}`
- 示例: `openclaw-feishu-001`、`openclaw-qq-001`、`openclaw-wecom-100`

---

### 2. 工作空间规范

**文档**: [工作空间约定.md](./工作空间约定.md)

**规则**:
- 生产环境: `workspace/lobsters/`
- 测试环境: `test-workspace/`

---

### 3. 文档编写规范

**文档**: [文档编写规范.md](./文档编写规范.md)

**规则**:
- ✅ 所有文档放在 `docs/` 的子目录下
- ❌ 禁止在项目根目录创建文档
- ✅ 按类型分类（使用指南/问题解决/规范约定/技术参考）

**原因**: 保持根目录整洁，文档结构清晰

---

### 4. 跨平台要求

**规则**:
- ✅ 所有脚本使用 Python 3.8+
- ❌ 禁止 Shell 脚本（.sh）
- ❌ 禁止 Windows 批处理（.bat）

**原因**: 确保 Windows/Linux/macOS 全平台可用

---

### 5. Python 版本要求

**文档**: [Python版本要求.md](./Python版本要求.md) 🆕

**规则**:
- ✅ 最低版本: Python 3.10
- ✅ 推荐版本: Python 3.12+
- ✅ 目标版本: Python 3.12.8（`.python-version`）
- ✅ env-checker 自动安装: 3.12.8

**原因**: 平衡兼容性和性能

---

### 6. 虚拟环境规范

**文档**: [虚拟环境管理规范.md](./虚拟环境管理规范.md) 🆕

**规则**:
- ✅ **所有 Python 脚本必须在虚拟环境中运行**
- ✅ 虚拟环境目录: `.venv/`（隐藏目录）
- ✅ 使用 `env-checker` 技能包初始化
- ❌ 禁止在系统 Python 环境中运行脚本
- ❌ 禁止在根目录创建 `venv/` 目录

**原因**: 隔离依赖，确保环境一致，避免冲突

## ⚠️ 违反规范的后果

| 违规 | 后果 | 示例 |
|------|------|------|
| 根目录创建文档 | 项目结构混乱 | `快速入门.md` 而不是 `docs/01-使用指南/快速入门.md` |
| 命名不规范 | 工具无法识别 | `my-bot` 而不是 `openclaw-feishu-001` |
| 使用Shell脚本 | Windows无法运行 | `approve_pairing.sh` |
| 工作空间错误 | 配置混乱 | 测试和生产数据混在一起 |
