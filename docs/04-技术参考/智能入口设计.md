## 🎯 为什么需要智能入口？

### 传统方式的问题

**用户想创建一个飞书机器人**，传统方式需要：

```bash
# 步骤1: 安装 OpenClaw
git clone https://github.com/openclaw/openclaw
cd openclaw && npm install

# 步骤2: 创建实例
./openclaw-cli create-instance openclaw-prod-01 \
  --workspace /path/to/workspace

# 步骤3: 安装飞书插件
./openclaw-cli install-plugin feishu --instance openclaw-prod-01

# 步骤4: 配置渠道
./openclaw-cli add-channel \
  --instance openclaw-prod-01 \
  --platform feishu \
  --app-id cli_xxx \
  --app-secret yyy

# 步骤5: 添加模型
./openclaw-cli add-model \
  --instance openclaw-prod-01 \
  --model gpt-3.5-turbo \
  --provider openai \
  --api-key sk-xxx

# 步骤6: 创建智能体
./openclaw-cli create-agent \
  --instance openclaw-prod-01 \
  --name customer-service

# 步骤7: 绑定配置
./openclaw-cli bind-agent \
  --instance openclaw-prod-01 \
  --agent customer-service \
  --model gpt-3.5-turbo \
  --channel feishu

# 步骤8: 启动实例
./openclaw-cli start openclaw-prod-01
```

**问题**:
- ❌ 需要记忆 8 个命令
- ❌ 需要理解 30+ 个参数
- ❌ 需要手动编排执行顺序
- ❌ 容易出错，难以调试

### 有了 AGENTS.md 智能入口

**同样的需求，用户体验**:

```
用户: 创建一个飞书客服机器人

AI: 好的！请提供：
    1. 飞书的 App ID？
    2. 飞书的 App Secret？

用户: App ID 是 cli_xxx, Secret 是 yyy

AI: ⏳ 正在创建...
    
    ✅ [1/7] 创建实例
    ✅ [2/7] 安装飞书插件

    ✅ [6/7] 绑定配置
    ✅ [7/7] 启动实例

```

**优势**:
- ✅ 只需 2 轮对话
- ✅ 只需提供 2 个必需信息
- ✅ AI 自动完成 7 个步骤
- ✅ 自动决策所有参数

#### Complex 模式（多步任务）

**适用场景**: 创建、部署、配置

**示例**: "创建飞书客服机器人"

```
用户需求
    ↓
阶段1: 信息收集（询问必需信息）
    ↓
阶段2: 自动决策（选择配置）
    ↓
阶段3: 流程编排（7步串联）
  [1/7] 创建实例
  [2/7] 安装插件
  [3/7] 配置渠道
  [4/7] 添加模型
  [5/7] 创建智能体
  [6/7] 绑定配置
  [7/7] 启动实例
    ↓
阶段4: 验证（健康检查）
    ↓
阶段5: 友好反馈
    ↓
完成（<30秒）
```

**实现**:
```python
def handle_create_feishu_chatbot():
    # 阶段1: 收集信息
    name = ask_or_generate("实例名称", default="openclaw-prod-01")
    app_id = ask_required("飞书 App ID")
    app_secret = ask_required("飞书 App Secret")
    
    # 阶段2: 自动决策
    model = "gpt-3.5-turbo"  # 客服场景
    deploy = "host"          # 默认
    
    # 阶段3: 流程编排
    progress = ProgressBar(7)
    
    progress.update(1, "创建实例")
    call_tool("openclaw-manager", "create", name=name)
    
    progress.update(2, "安装飞书插件")
    call_tool("openclaw-plugin", "install", platform="feishu", instance=name)
    
    progress.update(3, "配置渠道")
    call_tool("openclaw-channel", "add", platform="feishu", app_id=app_id, app_secret=app_secret)
    
    progress.update(4, "添加模型")
    call_tool("openclaw-model", "add", model=model, provider="openai")
    
    progress.update(5, "创建智能体")
    call_tool("openclaw-agent", "create", name="customer-service")
    
    progress.update(6, "绑定配置")
    call_tool("openclaw-agent", "bind", agent="customer-service", model=model, channel="feishu")
    
    progress.update(7, "启动实例")
    call_tool("openclaw-manager", "start", name=name)
    
    # 阶段4: 验证
    health = call_tool("openclaw-deploy", "health-check", instance=name)
    
    # 阶段5: 反馈
    return f"🎉 飞书客服机器人 '{name}' 已就绪！"
```

#### Interactive 模式（引导式任务）

**适用场景**: 用户需求不明确

```
用户需求（模糊）
    ↓
```

```python
def handle_vague_request():
    # Q1: 用途
    purpose = ask_choice(
        "这个 AI 助手主要做什么？",

        "用于什么环境？",

    # 转换为明确需求 → Complex 模式
```

## 🎯 智能决策引擎

### 决策树

```
用户需求: "创建客服机器人"
           ↓
决策点1: 环境类型
  ├─ 用户说"测试" → 测试环境
  ├─ 用户说"生产" → 生产环境
  └─ 未说明 → 默认生产环境 ✅
           ↓
决策点2: 部署模式
  ├─ 环境=生产 → Docker ✅
  ├─ 环境=测试 → 主机模式
  └─ 用户说"K8s" → Kubernetes
           ↓
决策点3: AI 模型
  ├─ 用途=客服 → gpt-3.5-turbo ✅
  ├─ 用途=技术支持 → gpt-4
  ├─ 用途=创作 → gpt-4
  └─ 未说明 → gpt-3.5-turbo（默认）
           ↓
决策点4: 实例命名
  ├─ 用户提供 → 使用用户名称
  ├─ 生产环境 → openclaw-prod-{auto_num} ✅
  └─ 测试环境 → openclaw-test-{auto_num}
           ↓
最终决策:
  name: openclaw-prod-01
  deploy: docker
  model: gpt-3.5-turbo
  platform: feishu (用户已说明)
```

### 决策优先级

```
1. 用户明确说明 > 自动推断 > 默认值
2. 安全配置 > 性能配置 > 成本配置
3. 简单方式 > 复杂方式
```

**示例**:
```
场景: 用户说"部署"但没说模式

决策链:
  1. 用户说了吗？ ❌
  2. 能从上下文推断吗？
     - 用户提到"生产"？ ✅ → Docker
     - 用户提到"测试"？ → 主机模式
     - 都没有？ → 主机模式（最简单）
```

## 🎯 智能决策表详解

### 决策维度汇总

| 维度 | 输入 | 输出 | 决策依据 |
|-----|------|------|---------|
| 环境类型 | 用户语境 | prod/test | 关键词"生产/测试" |
| 部署模式 | 环境类型 | host/docker/k8s | 生产→docker，测试→host |
| AI模型 | 用途 | gpt-4/3.5 | 客服→3.5，技术→4 |
| 实例命名 | 环境+序号 | openclaw-{env}-{num} | 自动编号 |
| 日志级别 | 环境类型 | DEBUG/INFO | 开发→DEBUG，生产→INFO |
| 端口号 | 可用性检查 | 3000/3001/... | 检测占用，自动递增 |

### 决策算法伪代码

```python
def auto_decide_config(user_intent, context):
    config = {}
    
    # 决策: 环境类型
    if "生产" in user_intent or "production" in user_intent:
        config["env"] = "prod"
    elif "测试" in user_intent or "test" in user_intent:
        config["env"] = "test"
    else:
        config["env"] = "prod"  # 默认生产
    
    # 决策: 部署模式
    if "docker" in user_intent.lower():
        config["deploy"] = "docker"
    elif "k8s" in user_intent.lower() or "kubernetes" in user_intent.lower():
        config["deploy"] = "k8s"
    else:
        config["deploy"] = "docker" if config["env"] == "prod" else "host"
    
    # 决策: AI 模型
    purpose = extract_purpose(user_intent)  # 提取用途
    if purpose in ["客服", "咨询"]:
        config["model"] = "gpt-3.5-turbo"
    elif purpose in ["技术支持", "编程"]:
        config["model"] = "gpt-4"
    elif purpose in ["内容创作", "写作"]:
        config["model"] = "gpt-4"
    else:
        config["model"] = "gpt-3.5-turbo"  # 默认
    
    # 决策: 实例命名
    if user_provided_name := extract_name(user_intent):
        config["name"] = user_provided_name
    else:
        auto_num = get_next_instance_number(config["env"])
        config["name"] = f"openclaw-{config['env']}-{auto_num:02d}"
    
    return config
```

## 📊 性能和效率

### 响应时间目标

| 任务复杂度 | 目标时间 | 示例 |

| Simple | <5秒 | 查看状态 |

### 并行优化

**串行执行**（慢）:
```
创建实例（5秒）
  ↓
安装插件（10秒）
  ↓
配置渠道（3秒）
  ↓
总计: 18秒
```

**并行执行**（快）:
```
创建实例（5秒）
  ↓
┌──────────┬──────────┐
│ 安装插件  │ 添加模型  │ (并行执行)
│ (10秒)   │ (8秒)    │
└──────────┴──────────┘
  ↓
配置渠道（3秒）
  ↓
总计: 13秒（节省28%）
```

**AGENTS.md 中可以定义并行任务**:

```python
class IntentRecognizer:
    def __init__(self):
        self.handlers = [
            CreateIntentHandler(),
            QueryIntentHandler(),
            ConfigIntentHandler(),
            OperationIntentHandler(),
        ]
    
    def recognize(self, user_input):
        for handler in self.handlers:
            if intent := handler.handle(user_input):
                return intent
        return UnknownIntent()
```
