## 📂 目录说明

### 核心目录

#### skills/
- **作用**: 存放所有 Cursor 技能包
- **特点**: 每个子目录是一个独立的技能包
- **规范**: 每个技能包必须有 SKILL.md 文件
- **提交**: ✅ 提交到 Git

#### workspace/
- **作用**: 存放所有 OpenClaw 实例的运行数据
- **特点**: 每个实例有独立的子目录
- **内容**: 配置、数据、日志、插件数据
- **提交**: ❌ 不提交到 Git（隐私保护）

#### docs/
- **作用**: 项目级文档
- **内容**: 需求分析、技术调研、使用指南等
- **提交**: ✅ 提交到 Git

#### shared/
- **作用**: 跨技能包共享的资源
- **内容**: 全局配置、工具函数
- **提交**: ✅ 提交到 Git（不包含敏感信息）

### 技能包内部结构

每个技能包遵循统一的结构：

```
skill-name/
├── SKILL.md              # 必需 - 技能包主文件（<500行）
├── reference/            # 可选 - 详细参考文档
│   └── *.md
├── scripts/              # 可选 - 工具脚本
│   ├── *.py
│   ├── *.sh
│   └── requirements.txt
└── templates/            # 可选 - 配置模板
    └── *
```

## 🔐 安全相关目录

### 不提交到 Git 的目录和文件

```
workspace/                    # 所有运行数据
**/.env                          # 环境变量
**/config/secrets.yaml           # 密钥配置
**/config/credentials.json       # 凭证文件
logs/                            # 日志文件

cache/                           # 缓存
node_modules/                    # 依赖

```

详见 `.gitignore` 文件的完整配置。

## 📊 目录大小估算

| 目录 | 预计大小 | 说明 |
|------|---------|------|
| skills/ | 1-5 MB | 技能包代码和文档 |
| workspace/ | 100MB-10GB | 取决于实例数量和运行时间 |
| docs/ | <1 MB | 项目文档 |
| shared/ | <1 MB | 共享资源 |

**注意**: workspace/ 目录会随着使用增长，建议定期清理和备份。

## 🔄 版本控制策略

### 提交到 Git
```
✅ 技能包代码（skills/）
✅ 配置模板（templates/）
✅ 工具脚本（scripts/）
✅ 项目文档（docs/）
✅ 共享配置模板（shared/configs/*.template）
✅ README 和配置文件
```

### 不提交到 Git
```
❌ 工作空间（workspace/）
❌ 运行日志（logs/）
❌ 环境变量（.env）
❌ 敏感凭证（secrets, credentials）
❌ 依赖目录（node_modules/, __pycache__/）
❌ 临时文件（*.tmp, *.log）
```

## 🎨 目录命名规范

### 技能包命名
- 格式：`openclaw-{功能}`
- 示例：`openclaw-manager`, `openclaw-deploy`
- 规则：小写，连字符分隔，描述性强

### 实例命名
- 格式：`openclaw-{环境}-{编号}`
- 示例：`openclaw-prod-01`, `openclaw-dev-01`
- 规则：环境标识 + 数字编号

### 文件命名
- 技能包主文件：`SKILL.md`（固定，必需）
- 参考文档：`kebab-case.md`（小写，连字符）
- 脚本：`snake_case.py`, `kebab-case.sh`
- 配置模板：`name.template` 或 `name.example`
