## 🐛 根本原因分析

### 可能原因 1: OpenClaw 连接超时

OpenClaw Gateway 在收到 `chat.send` 请求后：
1. 向 Ollama 发起请求
2. Ollama 开始思考（30-40 秒）
3. **期间 WebSocket 连接可能被认为"空闲"而断开**

### 可能原因 2: Ollama 无法访问

OpenClaw 无法连接到 `host.docker.internal:11434`

### 可能原因 3: 工作空间未初始化

Agent 的工作空间路径不存在或未正确挂载

---

## 🔧 解决方案

### 步骤 1: 验证 Ollama 连通性

```bash
# 从 OpenClaw Pod 内部测试
kubectl exec -n openclaw <openclaw-pod-name> -- \
  curl -s http://host.docker.internal:11434/api/version

# 预期输出: {"version":"0.x.x"}
```

### 步骤 2: 检查 OpenClaw 日志

```bash
# 查看详细错误
kubectl logs -n openclaw <openclaw-pod-name> --tail=100

# 关键词: ollama, timeout, connection, error
```

### 步骤 3: 增加 WebSocket 保活

修改 `scheduler-go/internal/websocket/pool.go`:

```go
// 在连接建立后设置保活
conn.SetPingHandler(func(appData string) error {
    conn.WriteControl(websocket.PongMessage, []byte{}, time.Now().Add(10*time.Second))
    return nil
})

// 启动心跳 goroutine
go func() {
    ticker := time.NewTicker(30 * time.Second)
    defer ticker.Stop()
    for {
        select {
        case <-ticker.C:
            if err := conn.WriteControl(websocket.PingMessage, []byte{}, time.Now().Add(10*time.Second)); err != nil {
                return
            }
        }
    }
}()
```

### 步骤 4: 添加 Agent 注册检查

在 `ChatStream` 中添加验证：

```go
// 确保 Agent 已在 OpenClaw 中注册
addCmd := []string{"node", "openclaw.mjs", "agents", "list"}
stdout, _, err := k8s.ExecCommand("openclaw", container.PodName, addCmd)
if !strings.Contains(stdout, req.AgentID) {
    // Agent 不存在，需要创建
    addCmd = []string{
        "node", "openclaw.mjs", "agents", "add",
        req.AgentID,
        "--workspace", fmt.Sprintf("/data/agents/%s", req.AgentID),
        "--agent-dir", fmt.Sprintf("/data/agents/%s/agent", req.AgentID),
        "--non-interactive",
    }
    k8s.ExecCommand("openclaw", container.PodName, addCmd)
}
```
