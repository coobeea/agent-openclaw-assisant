# 🧪 WebSocket 流式输出测试指南

## 快速测试（3种方法）

### 方法 1：使用测试脚本（最简单）

```bash
./test-streaming.sh
```

选择选项 2（K8s 内部测试）即可。

---

### 方法 2：手动 K8s 内部测试（推荐）

```bash
# 直接在 K8s 内部测试
kubectl run test-streaming --rm -i --restart=Never \
  --image=curlimages/curl:latest -n openclaw -- \
  curl -N -X POST http://openclaw-scheduler:8080/api/chat/stream \
    -H 'Content-Type: application/json' \
    -d '{"agent_id":"test-agent","message":"你好，用10个字回复"}'
```

**预期输出**（15-30秒内）：
```
data: {"choices":[{"delta":{"content":"你好！很高兴见到你..."},"finish_reason":null,"index":0}],...}
```

---

### 方法 3：本地测试（通过端口转发）

**步骤 1：端口转发（终端 1）**
```bash
kubectl port-forward -n openclaw svc/openclaw-scheduler 8080:8080
```

**步骤 2：测试请求（终端 2）**
```bash
curl -N -X POST http://localhost:8080/api/chat/stream \
  -H 'Content-Type: application/json' \
  -d '{"agent_id":"test-agent","message":"你好，简单介绍你自己"}' \
  | jq -r '.choices[0].delta.content' 2>/dev/null || cat
```

## 查看日志

### 查看 Scheduler 日志
```bash
kubectl logs -n openclaw -l app=openclaw-scheduler --tail=50 -f
```

**关键日志标记**：
- `✅ [WSPool] HelloOk 收到，连接成功` - WebSocket 握手成功
- `✅ [ChatStream] 请求已接受` - chat.send 请求被接受
- `💬 [ChatStream] 实时输出: ...` - 流式文本输出
- `✅ [ChatStream] 对话完成` - 会话结束

### 查看 OpenClaw Gateway 日志
```bash
kubectl logs -n openclaw -l app=openclaw-pool --tail=50 -f
```

## 故障排查

### 问题 1：超时无响应

**检查**：
```bash
# 检查 Scheduler 是否就绪
kubectl get pods -n openclaw -l app=openclaw-scheduler

# 检查 OpenClaw Pool 是否就绪
kubectl get pods -n openclaw -l app=openclaw-pool

# 检查 Ollama 是否可访问
kubectl exec -n openclaw openclaw-pool-xxx -- \
  curl -s http://host.docker.internal:11434/api/tags
```

### 问题 2：连接被拒绝

**原因**: WebSocket 握手失败

**解决**：
```bash
# 重启 Scheduler
kubectl rollout restart deployment/openclaw-scheduler -n openclaw

# 重启 OpenClaw Pool
kubectl rollout restart deployment/openclaw-pool -n openclaw

# 等待就绪
kubectl wait --for=condition=ready pod -l app=openclaw-scheduler -n openclaw --timeout=60s
```

### 问题 3：收到错误响应

**检查日志**：
```bash
# 查看详细错误
kubectl logs -n openclaw -l app=openclaw-scheduler --tail=100 | grep -E "ERROR|error|失败"
```

## 前端集成示例

### JavaScript (EventSource)

```javascript
const eventSource = new EventSource('http://localhost:8080/api/chat/stream', {
  method: 'POST',
  headers: {
    'Content-Type': 'application/json'
  },
  body: JSON.stringify({
    agent_id: 'test-agent',
    message: '你好'
  })
});

eventSource.onmessage = (event) => {
  if (event.data === '[DONE]') {
    eventSource.close();
    return;
  }
  
  const data = JSON.parse(event.data);
  const content = data.choices[0].delta.content;
  console.log('收到：', content);
  
  // 更新 UI
  document.getElementById('output').innerText += content;
};

eventSource.onerror = (error) => {
  console.error('错误:', error);
  eventSource.close();
};
```

### JavaScript (Fetch Streaming)

```javascript
const response = await fetch('http://localhost:8080/api/chat/stream', {
  method: 'POST',
  headers: {
    'Content-Type': 'application/json'
  },
  body: JSON.stringify({
    agent_id: 'test-agent',
    message: '你好'
  })
});

const reader = response.body.getReader();
const decoder = new TextDecoder();

while (true) {
  const { value, done } = await reader.read();
  if (done) break;
  
  const chunk = decoder.decode(value);
  const lines = chunk.split('\n');
  
  for (const line of lines) {
    if (line.startsWith('data: ')) {
      const data = line.slice(6);
      if (data === '[DONE]') {
        console.log('完成');
        return;
      }
      
      const json = JSON.parse(data);
      const content = json.choices[0].delta.content;
      console.log('收到：', content);
    }
  }
}
```
