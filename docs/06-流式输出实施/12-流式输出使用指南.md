## 🐛 故障排查

### 问题 1：报错"没有可用的容器"

**原因**: 所有容器被标记为 busy

**解决**:
```bash
# 重启 Scheduler 清空状态
kubectl rollout restart deployment/openclaw-scheduler -n openclaw
```

### 问题 2：前端无响应

**检查步骤**:
```bash
# 1. 检查 Scheduler 日志
kubectl logs -n openclaw -l app=openclaw-scheduler --tail=50

# 2. 检查容器池状态
curl http://localhost:30080/api/containers/status

# 3. 测试 API 是否正常
curl http://localhost:30080/health
```

### 问题 3：流式输出卡住

**可能原因**:
1. 模型思考时间长（正常，等待 30-40 秒）
2. Ollama 服务未运行
3. WebSocket 连接断开

**检查 Ollama**:
```bash
curl http://host.docker.internal:11434/api/version
```
