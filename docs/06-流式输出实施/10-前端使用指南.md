# 前端使用指南

## 🌐 访问地址

```
http://localhost:30000
```

如果 30000 端口无法访问，也可以使用：
```
http://127.0.0.1:30000
```

---

## 🎨 界面功能

### 1️⃣ 用户系统
- **注册/登录**: 首次访问需要注册账号
- **用户隔离**: 每个用户有独立的智能体空间
- **会话保持**: 登录状态会自动保存

### 2️⃣ 智能体管理
- **创建智能体**: 点击"创建"按钮，输入名称和描述
- **智能体列表**: 左侧显示所有智能体，点击选择
- **智能体状态**: 绿点表示已激活

### 3️⃣ 对话功能
- **流式输出**: 实时显示 AI 回复（已启用 WebSocket）
- **思维链**: AI 的思考过程可折叠展示
- **对话历史**: 自动保存，切换智能体时加载
- **消息发送**: 输入框支持 Enter 发送

---

## 🔧 技术架构

```
用户浏览器
    ↓ (HTTP 30000)
Nginx 前端代理
    ↓ (SSE /api/chat/stream)
Go Scheduler (8080)
    ↓ (WebSocket)
OpenClaw Gateway (K8s Pod)
    ↓
Ollama (gemma4:e4b)
```

### 网络流程

1. **前端 → Nginx**: 
   - 静态文件: `http://localhost:30000/`
   - API 请求: `http://localhost:30000/api/*`

2. **Nginx → Scheduler**:
   - `/api` 代理到 `http://openclaw-scheduler:8080`
   - 支持 SSE 流式传输（`proxy_buffering off`）

3. **Scheduler → OpenClaw**:
   - WebSocket 连接到分配的 Pod IP
   - 实现协议转换（SSE → WebSocket）

## 📋 使用步骤

### 第一步：注册账号
1. 打开 http://localhost:30000
2. 点击"没有账号？立即注册"
3. 输入用户名和密码
4. 点击"注册"

### 第二步：创建智能体
1. 登录后，点击"创建"按钮（左上角）
2. 输入智能体名称（例如：测试助手）
3. 输入描述（可选）
4. 点击"创建智能体"

### 第三步：开始对话
1. 左侧智能体列表中，点击选择智能体
2. 右侧会显示对话界面
3. 在底部输入框输入消息
4. 按 Enter 或点击发送按钮
5. 等待 AI 流式回复（通常 30-45 秒）

## 🔍 故障排查

### 1. 无法访问前端
```bash
# 检查服务状态
kubectl get pods,svc -n openclaw -l app=frontend

# 查看日志
kubectl logs -n openclaw -l app=frontend --tail=50
```

### 2. 对话无响应
```bash
# 检查 Scheduler 日志
kubectl logs -n openclaw -l app=openclaw-scheduler --tail=100

# 检查 OpenClaw 日志
kubectl logs -n openclaw -l app=openclaw --tail=100
```

### 3. 流式输出中断
- 检查 Ollama 是否正常: `curl http://host.docker.internal:11434/api/version`
- 检查模型是否存在: `ollama list | grep gemma4:e4b`
