# 容器状态管理问题与解决方案

## 🐛 问题描述

### 现象
前端访问 `http://localhost:30000/api/chat/stream` 时报错：
```
503 Service Unavailable
```

### 根本原因
Scheduler 日志显示：
```
❌ [ChatStream] 容器分配失败: 没有可用的容器
```

**所有容器都被标记为 `busy` 状态，无法分配新的容器！**

---

## 🔍 问题分析

### 当前容器管理逻辑

```go
// AllocateContainer - 分配时标记为 busy
poolStatus[selectedPod] = PoolStatus{
    Status:    "busy",
    AgentID:   agentID,
}

// ReleaseContainer - 需要手动调用才会释放
poolStatus[podName] = PoolStatus{
    Status:  "idle",
}
```

**问题**：
1. ✅ 分配容器时自动标记为 `busy`
2. ❌ **从不自动释放**（没有调用 `ReleaseContainer`）
3. ❌ **容器池很快被耗尽**

### 为什么没有自动释放？

查看 `ChatStream` 函数（`scheduler-go/internal/api/api.go`）：

```go
func ChatStream(c *gin.Context) {
    // 1. 分配容器
    container, err := k8s.AllocateContainer(req.AgentID)
    
    // 2. 处理对话
    // ... 流式输出逻辑 ...
    
    // 3. ❌ 没有调用 k8s.ReleaseContainer()
}
```

**缺少释放逻辑！**

---

## 🔧 临时解决方案（当前使用）

### 方法：重启 Scheduler

```bash
# 重启 Scheduler Pod（会清空内存中的状态）
kubectl delete pod -n openclaw -l app=openclaw-scheduler

# 等待新 Pod 启动
kubectl get pods -n openclaw -l app=openclaw-scheduler
```

**效果**：立即清空所有容器状态，所有容器变为 `idle`

**缺点**：
- 需要手动操作
- 治标不治本
- 每次容器耗尽都要重启

## ✅ 长期解决方案

### 方案 A：添加会话保持机制（推荐⭐）

**理念**：容器应该与 Agent 会话绑定，会话结束后释放

#### 实现步骤

1. **修改分配逻辑**（`k8s/k8s.go`）：

```go
func AllocateContainer(agentID string) (*models.ContainerStatus, error) {
    mu.Lock()
    defer mu.Unlock()

    // ✅ 检查是否有现有会话（复用容器）
    if podName, exists := agentSessions[agentID]; exists {
        pod, err := clientset.CoreV1().Pods("openclaw").Get(...)
        if err == nil && pod.Status.Phase == "Running" {
            // 更新最后活跃时间
            poolStatus[podName] = PoolStatus{
                Status:       "busy",
                AgentID:      agentID,
                LastActivity: time.Now().Unix(),
            }
            return &models.ContainerStatus{...}, nil
        }
    }
    
    // 分配新容器...
}
```

2. **添加自动清理 Goroutine**（`main.go`）：

```go
func main() {
    // ... 初始化 ...
    
    // 启动容器清理任务
    go cleanupIdleContainers()
    
    // ... 启动服务器 ...
}

func cleanupIdleContainers() {
    ticker := time.NewTicker(5 * time.Minute)
    defer ticker.Stop()
    
    for range ticker.C {
        k8s.CleanupIdleContainers(30 * time.Minute) // 30分钟无活动则释放
    }
}
```

3. **实现清理逻辑**（`k8s/k8s.go`）：

```go
func CleanupIdleContainers(timeout time.Duration) {
    mu.Lock()
    defer mu.Unlock()
    
    now := time.Now().Unix()
    for podName, status := range poolStatus {
        if status.Status == "busy" {
            idle := now - status.LastActivity
            if idle > int64(timeout.Seconds()) {
                log.Printf("🧹 释放空闲容器: %s (空闲 %d 秒)", podName, idle)
                poolStatus[podName] = PoolStatus{Status: "idle"}
                delete(agentSessions, status.AgentID)
            }
        }
    }
}
```

### 方案 B：请求结束立即释放（简单但效率低）

**理念**：每次请求结束后立即释放容器

#### 实现

修改 `ChatStream` 函数：

```go
func ChatStream(c *gin.Context) {
    // 分配容器
    container, err := k8s.AllocateContainer(req.AgentID)
    if err != nil {
        // ... 错误处理
        return
    }
    
    // ✅ 添加 defer 确保释放
    defer k8s.ReleaseContainer(container.PodName, req.AgentID)
    
    // 处理流式输出...
}
```

**优点**：实现简单，立即生效  
**缺点**：无法复用容器，每次都要重新连接 WebSocket

### 方案 C：混合方案（最佳⭐⭐⭐）

**理念**：结合会话保持和自动清理

1. **同一 Agent 复用容器**（5分钟内）
2. **不同 Agent 重新分配**
3. **超过5分钟无活动自动释放**

#### 核心代码

```go
// AllocateContainer
func AllocateContainer(agentID string) (*models.ContainerStatus, error) {
    mu.Lock()
    defer mu.Unlock()

    // 1. 尝试复用（5分钟内）
    if podName, exists := agentSessions[agentID]; exists {
        status := poolStatus[podName]
        if time.Now().Unix() - status.LastActivity < 300 { // 5分钟
            // 更新活跃时间
            status.LastActivity = time.Now().Unix()
            poolStatus[podName] = status
            // 返回复用的容器
            return getContainerInfo(podName, agentID)
        }
        // 超过5分钟，释放旧容器
        delete(agentSessions, agentID)
        poolStatus[podName] = PoolStatus{Status: "idle"}
    }

    // 2. 分配新容器
    // ... 选择空闲Pod逻辑 ...
    
    poolStatus[selectedPod] = PoolStatus{
        Status:       "busy",
        AgentID:      agentID,
        LastActivity: time.Now().Unix(),
    }
    agentSessions[agentID] = selectedPod
    
    return getContainerInfo(selectedPod, agentID)
}

// 后台清理（10分钟运行一次）
func CleanupIdleContainers() {
    ticker := time.NewTicker(10 * time.Minute)
    for range ticker.C {
        mu.Lock()
        now := time.Now().Unix()
        for podName, status := range poolStatus {
            if status.Status == "busy" && now - status.LastActivity > 1800 { // 30分钟
                log.Printf("🧹 清理超时容器: %s", podName)
                poolStatus[podName] = PoolStatus{Status: "idle"}
                delete(agentSessions, status.AgentID)
            }
        }
        mu.Unlock()
    }
}
```
