# 新机器首次使用指南 🆕

> **在全新机器上从零开始部署 OpenClaw（使用 env-checker）**

---

## ⚠️ 重要前提

本指南适用于：
- ✅ 全新的机器（没有 OpenClaw 实例）
- ✅ 首次部署 OpenClaw
- ✅ 需要完整的初始化流程
- ✅ **系统可能没有Python** - env-checker 会自动安装！🌟

如果您已经有实例，请查看 [工具链使用指南.md](./工具链使用指南.md)

在开始之前，请准备好：

```bash
# 确认 OpenClaw 已安装

git clone <openclaw-repo-url> /Users/lifeng/git/git_agents/openclaw
```

### 2. 飞书应用凭证（如需飞书集成）
- 📝 App ID（如 `cli_a9238xxxxxxxxxxxxx`）
- 🔐 App Secret（如 `xxx...`）

**获取方式**:

### 第 1 步：确认环境

```bash

.venv/bin/python skills/openclaw-manager/scripts/instance_manager.py restart openclaw-feishu-001
```

## ❓ 常见问题

### Q1: 系统没有 Python 怎么办？

**不用担心！env-checker 会自动安装！** 🌟

直接运行：
```bash
bash skills/env-checker/scripts/setup.sh
```

env-checker 会：
1. 检测系统Python
2. 如果没有，自动从 python.org 下载
3. 自动安装（macOS用brew/pkg，Windows用exe）
4. 创建虚拟环境

---

### Q2: 为什么是 `.venv` 而不是 `venv`？

- ✅ `.venv` 是隐藏目录（以点开头）
- ✅ 不会在 `ls` 中显示，保持项目目录整洁
- ✅ 不影响项目外观
- ✅ 是 Python 社区和 env-checker 的推荐做法

---

### Q3: 飞书机器人一直要求配对？

参见 [飞书配对-真正的解决方案.md](../../02-问题解决/飞书配对-真正的解决方案.md)

**关键步骤**:
1. 用户给机器人发消息
2. 机器人回复配对请求
3. 运行 `channel_manager.py approve-pairing`
4. **重启实例**（必须！）

---

### Q4: 模型报 "Unknown model" 错误？

参见 [模型Unknown问题-解决方案.md](../../02-问题解决/模型Unknown问题-解决方案.md)

**快速修复**:
```bash
.venv/bin/python skills/openclaw-model/scripts/model_manager.py fix-config openclaw-feishu-001
.venv/bin/python skills/openclaw-manager/scripts/instance_manager.py restart openclaw-feishu-001
```

---

### Q5: 如何查看实例是否正常运行？

```bash
# 方式1: 查看实例列表
.venv/bin/python skills/openclaw-manager/scripts/instance_manager.py list

# 方式2: 查看进程
ps aux | grep openclaw

# 方式3: 查看日志
.venv/bin/python skills/openclaw-manager/scripts/instance_manager.py logs openclaw-feishu-001
```

---

### Q6: WebUI 无法访问？

参见 [WebUI访问-改进完成.md](../../02-问题解决/WebUI访问-改进完成.md)

**检查**:
1. 实例是否在运行
2. 端口是否被占用
3. 防火墙设置
