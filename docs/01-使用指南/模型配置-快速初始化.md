# 模型配置 - 快速初始化 🚀

> **一键导入常用模型配置，无需手动逐个添加**

---

## 🎯 为什么需要模板初始化？

### ❌ 传统方式的痛点

手动配置模型需要：
1. 查找每个模型的准确 ID
2. 逐个添加模型配置
3. 设置上下文窗口、输出限制等参数
4. 容易出现配置错误

**耗时**: 15-30 分钟

---

### ✅ 模板初始化的优势

一条命令完成：
- ✅ 导入 9 个常用模型
- ✅ 自动配置参数
- ✅ 设置默认模型
- ✅ 应用到实例

**耗时**: 10 秒

---

## 🚀 快速开始

### 第 1 步: 查看可用模板

```bash
python skills/openclaw-model/scripts/model_manager.py list-templates
```

**输出示例**:
```
📦 bailian-coding-models
   名称: 百炼 Coding 模型套餐
   描述: 百炼 coding.dashscope.aliyuncs.com 的推荐模型配置
   提供商: bailian
   模型数: 9
```

---

### 第 2 步: 使用模板初始化

```bash
python skills/openclaw-model/scripts/model_manager.py init-from-template \
  bailian-coding-models \
  sk-sp-your-api-key-here \
  --instance <实例名>
```

**会自动完成**:
1. ✅ 更新全局配置 (`workspace/data/models.json`)
2. ✅ 更新实例配置 (`.openclaw/openclaw.json`)
3. ✅ 添加所有模型到智能体可用列表
4. ✅ 设置 `qwen3.5-plus` 为默认模型

---

### 第 3 步: 重启实例

```bash
python skills/openclaw-manager/scripts/instance_manager.py restart <实例名>
```

## 🎯 常见使用场景

### 场景 1: 新建实例时初始化

```bash
# 1. 创建实例
python skills/openclaw-manager/scripts/instance_manager.py create <实例名>

# 2. 一键初始化模型（推荐！）
python skills/openclaw-model/scripts/model_manager.py init-from-template \
  bailian-coding-models \
  sk-sp-your-api-key \
  --instance openclaw-feishu-demo

# 3. 安装飞书插件
python skills/openclaw-plugin/scripts/plugin_manager.py install feishu <实例名>

# 4. 配置飞书渠道
python skills/openclaw-channel/scripts/channel_manager.py add \
  <实例名> \
  feishu \
  --app-id cli_xxx \
  --app-secret xxx

# 5. 启动实例
python skills/openclaw-manager/scripts/instance_manager.py start <实例名>
```

---

### 场景 2: 更换 API Key

```bash
# 使用新 API Key 重新初始化
python skills/openclaw-model/scripts/model_manager.py init-from-template \
  bailian-coding-models \
  sk-sp-new-api-key \
  --instance openclaw-feishu-demo

# 重启实例
python skills/openclaw-manager/scripts/instance_manager.py restart <实例名>
```

---

### 场景 3: 只更新全局配置

```bash
# 不指定 --instance，只更新全局配置
python skills/openclaw-model/scripts/model_manager.py init-from-template \
  bailian-coding-models \
  sk-sp-your-api-key

# 然后手动应用到实例
python skills/openclaw-model/scripts/model_manager.py fix-config <实例名>
```

## 🆚 对比：手动 vs 模板

### 手动配置（传统方式）

```bash
# 需要执行 9 次
python skills/openclaw-model/scripts/model_manager.py add bailian qwen3.5-plus sk-xxx
python skills/openclaw-model/scripts/model_manager.py add bailian kimi-k2.5 sk-xxx
python skills/openclaw-model/scripts/model_manager.py add bailian glm-5 sk-xxx
# ... 重复 9 次
```

**耗时**: 15-30 分钟  
**风险**: 容易出错、参数不一致

---

### 模板初始化（推荐）

```bash
# 一条命令完成
python skills/openclaw-model/scripts/model_manager.py init-from-template \
  bailian-coding-models \
  sk-sp-your-api-key \
  --instance openclaw-feishu-demo
```

**耗时**: 10 秒  
**优势**: 快速、准确、可复用

## 📝 创建自定义模板

如果您有自己的模型配置需求，可以创建自定义模板：

**位置**: `skills/openclaw-model/templates/your-template.json`

**格式**:
```json
{
  "name": "您的模板名称",
  "description": "模板描述",
  "provider": "bailian",
  "baseUrl": "https://your-api-endpoint.com/v1",
  "api": "openai-completions",
  "models": [
    {
      "id": "model-id",
      "name": "模型显示名称 (推荐)",
      "reasoning": false,
      "input": ["text", "image"],
      "cost": { "input": 0, "output": 0, "cacheRead": 0, "cacheWrite": 0 },
      "contextWindow": 131072,
      "maxTokens": 32768,
      "description": "模型描述"
    }
  ]
}
```
