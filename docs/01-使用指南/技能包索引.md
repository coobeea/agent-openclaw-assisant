# OpenClaw 技能包索引

> 本文档提供所有技能包的快速索引和使用指南

## ⭐ 核心入口：AGENTS.md

**在查看具体技能包之前，请先了解 [`AGENTS.md`](../AGENTS.md)**

`AGENTS.md` 是整个技能包系统的**智能入口文件**，它：

- 🧠 **意图识别** - 将用户的自然语言转换为具体操作
- 🔄 **流程编排** - 自动串联多个技能包完成复杂任务
- 🎯 **智能决策** - 自动选择最佳配置和参数
- 💬 **对话管理** - 提供友好的用户交互体验

**工作流程**:
```
用户自然语言需求
    ↓
AGENTS.md 识别意图
    ↓
调度相应技能包
    ↓
自动编排执行流程
    ↓
友好反馈结果
```

**示例**:
```
用户: "创建一个飞书客服机器人"
  ↓
AGENTS.md: 识别为 CREATE_WITH_PLATFORM 意图
  ↓
自动调用:
  - openclaw-manager (创建实例)
  - openclaw-plugin (安装飞书插件)
  - openclaw-channel (配置渠道)
  - openclaw-model (添加模型)
  - openclaw-agent (创建智能体)
  ↓
结果: "✅ 飞书客服机器人已就绪！"
```

详见 [AGENTS 配置说明](AGENTS配置说明.md)

## 📦 技能包列表

### 1. openclaw-manager（核心技能包）⭐

**路径**: `skills/openclaw-manager/`  
**优先级**: P0 必需  
**依赖**: 无

#### 功能概述
OpenClaw 的核心管理工具，负责安装、实例创建和生命周期管理。

#### 主要能力
- ✅ OpenClaw 安装（自动选择最佳方式）
- ✅ 实例创建和管理（create、start、stop、delete）
- ✅ 工作空间初始化和管理
- ✅ 实例状态监控
- ✅ 日志查看和分析

#### 使用场景
- 首次安装 OpenClaw
- 创建新的 OpenClaw 实例
- 启动/停止实例
- 查看实例状态和日志
- 管理多个实例

#### 示例命令（通过 Cursor AI）
```
- "帮我安装 OpenClaw"
- "创建一个生产实例 openclaw-prod-01"
- "启动 openclaw-prod-01"
- "查看 openclaw-prod-01 的日志"
- "列出所有实例"
```

- ✅ 服务健康检查
- ✅ 自动重启配置

#### 使用场景
- 部署 OpenClaw 到生产环境
- 配置 Systemd 服务
- 创建 Docker 容器
- Kubernetes 集群部署

#### 示例命令
```
- "把 openclaw-prod-01 部署为 Systemd 服务"
- "用 Docker 部署 openclaw-prod-01"
- "为 openclaw-prod-01 生成 K8s 部署文件"
- "检查 openclaw-prod-01 的健康状态"
```

#### 主要能力
- ✅ 插件发现和列表
- ✅ 插件安装/卸载
- ✅ 插件更新
- ✅ 插件状态监控
- ✅ 四大平台插件支持

#### 支持的插件
- 🐦 飞书 (Feishu)
- 🐧 QQ
- 💼 企业微信 (WeCom)
- 📱 钉钉 (DingTalk)

#### 使用场景
- 安装消息平台插件
- 更新插件版本
- 查看已安装的插件
- 卸载不需要的插件

#### 示例命令
```
- "为 openclaw-prod-01 安装飞书插件"
- "列出所有可用的插件"
- "更新 openclaw-prod-01 的所有插件"
- "查看已安装的插件状态"
```

### 4. openclaw-channel（渠道技能包）

**路径**: `skills/openclaw-channel/`  
**优先级**: P1 推荐  
**依赖**: openclaw-plugin

#### 功能概述
管理消息平台的渠道配置，包括凭证管理和连接测试。

#### 主要能力
- ✅ 渠道配置管理（增删改查）
- ✅ 凭证加密存储
- ✅ 渠道连接测试
- ✅ 渠道状态监控
- ✅ 多渠道并发支持

#### 使用场景
- 配置飞书 App ID 和 Secret
- 配置企业微信应用凭证
- 测试渠道连接
- 管理多个渠道
- 启用/禁用特定渠道

#### 示例命令
```
- "为 openclaw-prod-01 配置飞书渠道"
- "测试飞书渠道连接"
- "列出所有渠道及状态"
- "删除不用的 QQ 渠道"
```

#### 配置示例
```yaml
# 飞书渠道配置
channel:
  name: feishu-main
  type: feishu
  app_id: cli_xxxxxxxxxxxxx
  app_secret: <encrypted>
  enabled: true
```

创建和管理智能体，配置智能体与模型、渠道的绑定关系。

- ✅ 智能体创建和配置
- ✅ 智能体与模型绑定
- ✅ 智能体与渠道路由
- ✅ 智能体启用/禁用

- 为不同场景配置专用智能体（客服、技术支持等）
- 配置智能体使用特定的 AI 模型

```
openclaw-manager
```

```
所有 6 个技能包
```

## 🔄 技能包调用流程

### 典型工作流

```
1. 安装 OpenClaw
   openclaw-manager → install

2. 创建实例
   openclaw-manager → create

3. 部署实例
   openclaw-deploy → deploy (host/docker)

4. 安装插件
   openclaw-plugin → install

5. 配置渠道
   openclaw-channel → add

6. 配置模型
   openclaw-model → add

7. 创建智能体
   openclaw-agent → create

8. 启动实例
   openclaw-manager → start
```
