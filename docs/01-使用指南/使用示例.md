# OpenClaw 龙虾军团管理 - 使用示例

本文档提供完整的使用示例，从零开始创建一个完整的 OpenClaw 实例。

---

## 🚀 场景 1: 创建第一个实例

### 目标
创建一个生产环境的飞书客服机器人。

### 步骤

#### 1. 在 Cursor 中安装 OpenClaw

直接对 AI 说：
```
帮我安装 OpenClaw
```

或手动执行：
```bash
bash skills/openclaw-manager/scripts/install_openclaw.sh
```

#### 2. 创建实例

对 AI 说：
```
创建一个实例叫 openclaw-prod-01
```

或手动执行：
```bash
python skills/openclaw-manager/scripts/instance_manager.py create openclaw-prod-01
```

#### 3. 安装飞书插件

对 AI 说：
```
给 openclaw-prod-01 安装飞书插件
```

或手动执行：
```bash
python skills/openclaw-plugin/scripts/plugin_manager.py install feishu --instance openclaw-prod-01
```

#### 4. 配置飞书渠道

对 AI 说：
```
配置飞书渠道，App ID 是 cli_xxxxx，App Secret 是 yyyyy
```

或手动执行：
```bash
python skills/openclaw-channel/scripts/channel_manager.py add \
  --instance openclaw-prod-01 \
  --platform feishu \
  --app-id cli_xxxxxxxxxxxxx \
  --app-secret your_secret_here
```

#### 5. 添加 AI 模型

对 AI 说：
```
添加 gpt-4 模型，API Key 是 sk-xxxxx
```

或手动执行：
```bash
python skills/openclaw-model/scripts/model_manager.py add \
  --instance openclaw-prod-01 \
  --model gpt-4 \
  --provider openai \
  --api-key sk-xxxxxxxxxxxxx
```

#### 6. 创建客服智能体

对 AI 说：
```
创建一个客服智能体
```

或手动执行：
```bash
python skills/openclaw-agent/scripts/agent_manager.py create \
  --instance openclaw-prod-01 \
  --name customer-service \
  --description "飞书客服机器人"
```

#### 7. 绑定模型和渠道

```bash
# 绑定模型
python skills/openclaw-agent/scripts/agent_manager.py bind-model \
  --instance openclaw-prod-01 \
  --agent customer-service \
  --model gpt-4

# 绑定渠道
python skills/openclaw-agent/scripts/agent_manager.py bind-channel \
  --instance openclaw-prod-01 \
  --agent customer-service \
  --channel feishu
```

#### 8. 启动实例

对 AI 说：
```
启动 openclaw-prod-01
```

或手动执行：
```bash
python skills/openclaw-manager/scripts/instance_manager.py start openclaw-prod-01
```

#### 9. 查看状态

```bash
python skills/openclaw-manager/scripts/instance_manager.py status openclaw-prod-01
```

#### 10. 测试

在飞书中 @机器人 发送消息，测试响应。

## 🎯 场景 3: 多智能体配置

### 目标
在一个实例中创建多个智能体，分别处理不同业务。

### 架构

```
实例: openclaw-prod-03
  ├── customer-service (客服) → 飞书
  ├── tech-support (技术支持) → QQ
  └── sales (销售) → 企业微信
```

### 步骤

#### 1. 创建实例

```bash
python skills/openclaw-manager/scripts/instance_manager.py create openclaw-prod-03
```

#### 2. 安装所有插件

```bash
python skills/openclaw-plugin/scripts/plugin_manager.py install feishu --instance openclaw-prod-03
python skills/openclaw-plugin/scripts/plugin_manager.py install qq --instance openclaw-prod-03
python skills/openclaw-plugin/scripts/plugin_manager.py install wecom --instance openclaw-prod-03
```

#### 3. 配置渠道

```bash
# 飞书
python skills/openclaw-channel/scripts/channel_manager.py add \
  --instance openclaw-prod-03 \
  --platform feishu \
  --app-id cli_feishu \
  --app-secret feishu_secret

# QQ
python skills/openclaw-channel/scripts/channel_manager.py add \
  --instance openclaw-prod-03 \
  --platform qq \
  --app-id qq_bot_id \
  --app-secret qq_token

# 企业微信
python skills/openclaw-channel/scripts/channel_manager.py add \
  --instance openclaw-prod-03 \
  --platform wecom \
  --app-id wecom_corp_id \
  --app-secret wecom_secret
```

#### 4. 添加模型

```bash
# 快速模型（客服）
python skills/openclaw-model/scripts/model_manager.py add \
  --instance openclaw-prod-03 \
  --model gpt-3.5-turbo \
  --provider openai \
  --api-key sk-xxxxx

# 专业模型（技术支持）
python skills/openclaw-model/scripts/model_manager.py add \
  --instance openclaw-prod-03 \
  --model gpt-4 \
  --provider openai \
  --api-key sk-xxxxx

# 平衡模型（销售）
python skills/openclaw-model/scripts/model_manager.py add \
  --instance openclaw-prod-03 \
  --model claude-3-sonnet \
  --provider anthropic \
  --api-key sk-ant-xxxxx
```

#### 5. 创建智能体

```bash
# 客服智能体
python skills/openclaw-agent/scripts/agent_manager.py create \
  --instance openclaw-prod-03 \
  --name customer-service \
  --description "客服机器人"

# 技术支持智能体
python skills/openclaw-agent/scripts/agent_manager.py create \
  --instance openclaw-prod-03 \
  --name tech-support \
  --description "技术支持机器人"

# 销售智能体
python skills/openclaw-agent/scripts/agent_manager.py create \
  --instance openclaw-prod-03 \
  --name sales \
  --description "销售机器人"
```

#### 6. 绑定配置

```bash
# 客服 → gpt-3.5-turbo + 飞书
python skills/openclaw-agent/scripts/agent_manager.py bind-model \
  --instance openclaw-prod-03 --agent customer-service --model gpt-3.5-turbo
python skills/openclaw-agent/scripts/agent_manager.py bind-channel \
  --instance openclaw-prod-03 --agent customer-service --channel feishu

# 技术支持 → gpt-4 + QQ
python skills/openclaw-agent/scripts/agent_manager.py bind-model \
  --instance openclaw-prod-03 --agent tech-support --model gpt-4
python skills/openclaw-agent/scripts/agent_manager.py bind-channel \
  --instance openclaw-prod-03 --agent tech-support --channel qq

# 销售 → claude-3-sonnet + 企业微信
python skills/openclaw-agent/scripts/agent_manager.py bind-model \
  --instance openclaw-prod-03 --agent sales --model claude-3-sonnet
python skills/openclaw-agent/scripts/agent_manager.py bind-channel \
  --instance openclaw-prod-03 --agent sales --channel wecom
```

#### 7. 启动

```bash
python skills/openclaw-manager/scripts/instance_manager.py start openclaw-prod-03
```

## 🏢 场景 4: 企业级部署（K8s）

### 目标
在 Kubernetes 集群中部署多个实例。

### 步骤

#### 1. 准备实例

```bash
python skills/openclaw-manager/scripts/instance_manager.py create openclaw-k8s-01
python skills/openclaw-manager/scripts/instance_manager.py create openclaw-k8s-02
python skills/openclaw-manager/scripts/instance_manager.py create openclaw-k8s-03
```

#### 2. 生成 K8s 配置

对 AI 说：
```
为 openclaw-k8s-01 生成 Kubernetes 配置
```

或使用模板：
```bash
cp skills/openclaw-deploy/templates/kubernetes/deployment.yaml k8s-deployment.yaml
# 替换 INSTANCE_ID 为 openclaw-k8s-01
sed -i 's/INSTANCE_ID/openclaw-k8s-01/g' k8s-deployment.yaml
```

#### 3. 部署到集群

```bash
kubectl apply -f k8s-deployment.yaml
kubectl apply -f skills/openclaw-deploy/templates/kubernetes/service.yaml
```

#### 4. 查看状态

```bash
kubectl get pods -n openclaw
kubectl get svc -n openclaw
```

## 💡 高级用法

### 使用配置文件批量配置

1. 复制配置模板：
```bash
cp shared/configs/global.yaml.template shared/configs/global.yaml
```

2. 编辑配置：
```yaml
workspace_root: ./workspace
log_level: INFO
```

3. 技能包会自动读取配置。

### 凭证轮换

定期更换敏感凭证：

```bash
# 更新飞书凭证
python skills/openclaw-channel/scripts/channel_manager.py update \
  --instance openclaw-prod-01 \
  --channel feishu \
  --app-secret new_secret_here

# 更新模型 API Key
python skills/openclaw-model/scripts/model_manager.py update \
  --instance openclaw-prod-01 \
  --model gpt-4 \
  --api-key sk-new-key-here
```

### 备份和恢复

```bash
# 备份工作空间
tar -czf openclaw-prod-01-backup.tar.gz workspace/openclaw-prod-01/

# 恢复
tar -xzf openclaw-prod-01-backup.tar.gz -C workspace/
```

## 🐛 故障排除示例

### 问题 1: 实例无法启动

**症状**: 
```
❌ 启动失败: 端口已被占用
```

**解决**:
```bash
# 检查端口
lsof -i :3000

# 或查看其他实例
python skills/openclaw-manager/scripts/instance_manager.py list

# 停止冲突的实例
python skills/openclaw-manager/scripts/instance_manager.py stop openclaw-prod-01
```

### 问题 2: 渠道连接失败

**症状**:
```
❌ 渠道连接失败: 认证错误
```

**解决**:
```bash
# 测试连接
python skills/openclaw-channel/scripts/connection_test.py openclaw-prod-01 feishu

# 更新凭证
python skills/openclaw-channel/scripts/channel_manager.py update \
  --instance openclaw-prod-01 \
  --channel feishu \
  --app-secret new_secret
```

### 问题 3: 模型调用失败

**症状**:
```
❌ 模型调用失败: API Key 无效
```

**解决**:
```bash
# 检查模型配置
python skills/openclaw-model/scripts/model_manager.py list --instance openclaw-prod-01

# 更新 API Key
python skills/openclaw-model/scripts/model_manager.py update \
  --instance openclaw-prod-01 \
  --model gpt-4 \
  --api-key sk-new-key
```

## 📝 最佳实践

### 1. 命名规范

✅ **推荐**:
- `openclaw-prod-01`（生产-编号）
- `openclaw-test-feishu`（测试-平台）
- `openclaw-dev-alice`（开发-开发者）

❌ **不推荐**:
- `instance1`（不明确）
- `龙虾-01`（使用中文）
- `my_openclaw`（下划线而非横线）

### 2. 安全实践

- ✅ 使用不同的 API Key 用于开发和生产
- ✅ 定期轮换凭证（建议每 3 个月）
- ✅ 限制工作空间目录权限
- ✅ 备份密钥文件（`.keyfile`）

### 3. 部署实践

- ✅ 开发阶段使用主机模式（快速迭代）
- ✅ 测试阶段使用 Docker（环境隔离）
- ✅ 生产阶段使用 K8s（高可用）

### 4. 运维实践

- ✅ 定期查看日志
- ✅ 配置健康检查
- ✅ 定期备份工作空间
- ✅ 监控资源使用
