## ⚡ 重要：默认激进模式（零门槛）

**本项目所有实例默认采用"激进模式"配置，确保快速上手：**

✅ **Control UI**：完全无需任何认证！直接访问即可
✅ **渠道策略**：开放模式，无需配对即可使用
✅ **局域网访问**：Docker 模式支持局域网访问

**技术方案**：
- **主机模式**：loopback 绑定 + auth.mode=none（仅本机访问）
- **Docker 模式**：Nginx 代理 + loopback OpenClaw（局域网可访问，完全无认证）

**这意味着**：
- 创建实例后立即可用
- **无需任何 Token**，直接打开 URL 即可
- 添加渠道后立即可收发消息
- 无需手动批准配对请求
- 真正的零门槛体验

**访问示例**：
- 主机模式：`http://127.0.0.1:18800/`
- Docker 模式：`http://127.0.0.1:18900/`（可用局域网 IP 访问）

⚠️ **生产环境**？查看 [openclaw配置文件完全解读.md](../03-技术解读/openclaw配置文件完全解读.md) 了解如何切换到安全模式。
