## 🔄 实例生命周期

### 1. 创建实例

#### 方式 A: 使用 orchestrator（推荐）

```bash
python3 scripts/orchestrator.py
```

**交互式创建**:
- 自动分配端口
- 选择/创建模型
- 选择/创建渠道
- 启用插件
- ✅ **自动同步模型配置**（新增）
- ✅ **自动验证配置完整性**（新增）
- 一键启动

**优势**:
- 🎯 流程完整，不遗漏步骤
- 🎯 自动化程度高
- 🎯 内置配置验证

#### 方式 B: 使用 instance_manager

```bash
# 基础创建
python3 skills/openclaw-manager/scripts/instance_manager.py create \
  --name openclaw-feishu-3000 \
  --model bailian/qwen3.5-plus \
  --port 18900

# 新功能：✅ 自动同步模型配置
# 输出会显示：
# ⏳ 同步模型配置...
# ✅ 模型配置已同步
```

**适用场景**:
- 快速创建简单实例
- 脚本化批量创建
- 自定义参数

### 2. 启动实例

```bash
# 启动
python3 skills/openclaw-manager/scripts/instance_manager.py start <实例名>

# 输出会显示带 token 的 URL：
# 🎯 访问方式:
#    Web UI: http://127.0.0.1:18800/#token=xxx
```

**新功能**: ✅ 自动显示带认证 token 的 URL

### 3. 查看状态

```bash
# 查看单个实例
python3 skills/openclaw-manager/scripts/instance_manager.py status <实例名>

# 查看所有实例
python3 skills/openclaw-manager/scripts/instance_manager.py list
```

### 4. 停止/重启实例

```bash
# 停止
python3 skills/openclaw-manager/scripts/instance_manager.py stop <实例名>

# 重启
python3 skills/openclaw-manager/scripts/instance_manager.py restart <实例名>
```

### 5. 删除实例

```bash
# 删除（会提示确认）
python3 skills/openclaw-manager/scripts/instance_manager.py delete <实例名>
```

## 🔍 故障诊断

### 常见问题及解决

#### 1. "Unknown model" 错误

**症状**:
```
Agent failed before reply: Unknown model: bailian/qwen3.5-plus
```

**诊断**:
```bash
# 1. 检查实例配置
cat workspace/lobsters/openclaw-xxx/.openclaw/openclaw.json | python3 -m json.tool | grep -A 5 '"providers"'

# 2. 运行健康检查
python3 scripts/health_check.py
```

**解决**:
```bash
# 方案 1: 批量修复（推荐）
python3 scripts/fix_all_models.py

# 方案 2: 手动修复
# 编辑 workspace/lobsters/openclaw-xxx/.openclaw/openclaw.json
# 添加完整的 models.providers 配置

# 重启实例
python3 skills/openclaw-manager/scripts/instance_manager.py restart openclaw-xxx
```

**参考文档**: `docs/模型Unknown问题-解决方案.md`

---

#### 2. "gateway token missing" 错误

**症状**:
```
unauthorized: gateway token missing
```

**原因**: 访问 Web UI 时没有在 URL 中携带 token

**解决**:
```bash
# 获取带 token 的完整 URL
python3 skills/openclaw-manager/scripts/instance_manager.py status openclaw-xxx

# 输出会显示：
# 🌐 访问地址:
#    Web UI: http://127.0.0.1:18800/#token=xxx
```

**参考文档**: `docs/WebUI访问-改进完成.md`

---

#### 3. 命名不规范

**症状**:
```
⚠️  生产客服001: 发现 1 个问题
   ⚠️  [naming] 命名不规范: 包含中文字符
```

**解决**: 重新创建实例，使用规范命名

**规范**: `openclaw-{platform}-{sequence}`

**示例**:
- ✅ `openclaw-feishu-001` (飞书实例)
- ✅ `openclaw-qq-001` (QQ实例)
- ✅ `openclaw-wecom-100` (企业微信实例)
- ❌ `生产客服001` (包含中文)
- ❌ `OpenClaw-Test-01`（大写）

**参考文档**: `docs/龙虾命名规范.md`

## 🚨 故障处理流程

### 步骤 1: 快速诊断

```bash
# 1. 检查实例状态
python3 skills/openclaw-manager/scripts/instance_manager.py status <name>

# 2. 查看最新日志
tail -50 workspace/logs/<name>.log

# 3. 运行健康检查
python3 scripts/health_check.py
```

### 步骤 2: 问题分类

| 问题类型 | 特征 | 解决方案 |
|---------|------|----------|
| 模型配置 | "Unknown model" | `fix_all_models.py` |
| 认证问题 | "gateway token missing" | 使用 `status` 获取完整 URL |
| 命名问题 | 包含中文 | 重新创建规范实例 |
| 进程问题 | 🔴 未运行 | 检查日志，重启 |
| 端口冲突 | Address in use | 修改端口或停止冲突进程 |

### 步骤 3: 应用修复

```bash
# 模型配置问题
python3 scripts/fix_all_models.py
python3 skills/openclaw-manager/scripts/instance_manager.py restart <name>

# 命名问题
python3 skills/openclaw-manager/scripts/instance_manager.py delete <old-name>
python3 scripts/orchestrator.py  # 重新创建

# 进程问题
python3 skills/openclaw-manager/scripts/instance_manager.py restart <name>
```

### 步骤 4: 验证修复

```bash
# 1. 重新运行健康检查
python3 scripts/health_check.py

# 2. 查看实例状态
python3 skills/openclaw-manager/scripts/instance_manager.py status <name>

# 3. 检查日志（无错误）
tail -50 workspace/logs/<name>.log | grep -i error
```
