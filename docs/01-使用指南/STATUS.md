## 🎨 架构亮点

### 1. 软链接激活 ✨

```
源文件 (skills/)  →  软链接 (.cursor/skills/)  →  Cursor 识别
```

**优势**: 单一数据源，版本控制友好，实时生效

### 2. 工作空间保真设计 ⭐

**原则**:
- ❌ 不预定义 OpenClaw 内部结构
- ✅ 只创建顶层目录
- ✅ 路径可配置（相对/绝对/~）
- ✅ 通过 CLI 交互

### 3. 安全设计 🔒

- Fernet 对称加密
- 凭证自动遮罩显示
- 严格的 .gitignore
- 密钥文件权限控制

### 4. 统一命名 📝

- 实例: `openclaw-{env}-{num}`
- 智能体: `{instance}-agent-{name}`
- 英文前缀统一
