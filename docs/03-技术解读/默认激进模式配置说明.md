# 默认激进模式配置说明

## 📋 概述

从当前版本开始，**所有新创建的 OpenClaw 实例默认采用"激进模式"配置**，以实现零门槛、快速上手的目标。

---

## 🎯 激进模式特性

### 1. Control UI - 完全无需认证

**配置**：
```json
{
  "gateway": {
    "bind": "loopback",
    "port": 3000,
    "auth": {
      "mode": "none"
    },
    "controlUi": {
      "dangerouslyDisableDeviceAuth": true
    }
  }
}
```

**效果**：
- ✅ **完全无需认证**（auth.mode=none）
- ✅ 无需任何 Token
- ✅ 直接访问即可
- ✅ Docker 模式：通过 Nginx 代理支持局域网访问

**访问方式**：
```
# 主机模式（仅本机）
http://127.0.0.1:18800/

# Docker 模式（局域网可访问）
http://127.0.0.1:18900/
```

**技术方案**：
- **OpenClaw**: 监听 127.0.0.1:3000（loopback 模式，完全无认证）
- **Nginx**: 监听 0.0.0.0:18900，反向代理到 OpenClaw
- **结果**: 对外开放访问，内部无认证

### 2. 渠道策略 - 开放模式

**配置**：
```json
{
  "channels": {
    "feishu": {
      "accounts": {
        "xxx": {
          "dmPolicy": "open",
          "groupPolicy": "open"
        }
      }
    }
  }
}
```

**效果**：
- ✅ 私聊无需配对
- ✅ 群聊无需配对
- ✅ 添加渠道后立即可用

### 3. Gateway - 局域网访问

**配置**：
```json
{
  "gateway": {
    "bind": "lan",
    "port": 18900
  }
}
```

**效果**：
- ✅ 局域网内可访问（监听所有网络接口）
- ✅ 支持同一网络内其他设备访问
- ✅ 适合团队协作和容器化部署

### 修改的文件

#### 1. `skills/openclaw-manager/scripts/instance_manager.py`

**新增方法**：`_apply_aggressive_config()`

- 设置 `gateway.auth.mode = "token"`, `gateway.auth.token = "openclaw-dev-token"`

**修改点**：
- 第 110-116 行：多账号模式，设置 `dmPolicy = "open"`
- 第 119-127 行：单账号模式，设置 `dmPolicy = "open"`

**效果**：
- 添加飞书渠道时，自动设置为开放策略
- 无需手动批准配对请求

## ⚠️ 安全建议

### 适用场景

**激进模式适用于**：
- ✅ 开发环境
- ✅ 测试环境
- ✅ 快速验证功能
- ✅ 内网环境

**不推荐用于**：
- ❌ 公网生产环境
- ❌ 处理敏感数据
- ❌ 多用户共享环境

### 切换到安全模式

如需在生产环境使用，建议切换到安全模式：

1. **查看配置模板**：
   - `docs/03-技术解读/openclaw-config-templates/安全模式-生产环境配置.json`

2. **修改配置**：
   ```json
   {
     "gateway": {
       "host": "127.0.0.1",
       "auth": {
         "mode": "token",
         "token": "your-secure-token"
       }
     },
     "controlUI": {
       "dangerouslyDisableDeviceAuth": false
     },
     "channels": {
       "feishu": {
         "accounts": {
           "xxx": {
             "dmPolicy": "pairing",
             "groupPolicy": "pairing"
           }
         }
       }
     }
   }
   ```

3. **重启实例**：
   ```bash
   python skills/openclaw-manager/scripts/instance_manager.py restart <实例名>
   ```
