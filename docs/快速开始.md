# OpenClaw 管理技能包 - 快速开始

## 🎯 5分钟快速入门

### 步骤 1: 克隆项目

```bash
git clone <repo-url> agent-openclaw-assisant
cd agent-openclaw-assisant
```

### 步骤 2: 在 Cursor 中打开

```bash
cursor .
```

Cursor 会自动识别 `skills/` 目录下的所有技能包。

### 步骤 3: 与 AI 对话

在 Cursor 的聊天窗口中输入：

```
帮我安装 OpenClaw 并创建一个测试实例
```

AI 会自动：
1. 安装 OpenClaw
2. 创建实例 `openclaw-test-01`
3. 初始化工作空间
4. 返回启动命令

### 步骤 4: 验证安装

```
查看 openclaw-test-01 的状态
```

完成！🎉

## ⚠️ 注意事项

### 首次使用

1. **配置全局设置**: 复制 `shared/configs/global.yaml.template` 为 `global.yaml`
2. **安装依赖**: 运行 `npm install` 和 `pip install -r requirements.txt`
3. **检查权限**: 确保有执行脚本的权限

### 生产环境

1. **备份工作空间**: 定期备份 `workspace/` 目录
2. **保护敏感信息**: 不要将 `.env` 文件提交到 Git
3. **监控资源**: 注意实例的 CPU 和内存使用
4. **日志轮转**: 配置日志轮转，避免磁盘占满

### 多实例运行

1. **端口冲突**: 确保每个实例使用不同的端口
2. **资源隔离**: 监控各实例的资源使用
3. **命名规范**: 使用统一的命名前缀和环境标识

## 🆘 常见问题

### Q1: 如何查看可用的技能包？

```
用户: 列出所有 OpenClaw 相关的技能包
```

或查看 `docs/技能包索引.md`

### Q2: 技能包之间有依赖吗？

是的，依赖关系如下：
- `openclaw-channel` 依赖 `openclaw-plugin`
- `openclaw-agent` 依赖 `openclaw-model` 和 `openclaw-channel`
- 其他技能包依赖 `openclaw-manager`

### Q3: 如何更新 OpenClaw？

```
用户: 更新 OpenClaw 到最新版本
```

AI 会自动备份配置、更新 OpenClaw、恢复配置。

```

```

### Q5: 如何备份实例？

AI 会打包配置和重要数据。
