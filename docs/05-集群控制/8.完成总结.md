## 💡 核心设计亮点

### 1. 数据-计算分离

```
智能体数据 (灵魂)：
  ├── PostgreSQL（配置、历史）
  ├── MinIO（文件、资源）
  └── Redis（会话、缓存）

计算容器 (躯体)：
  ├── 无状态、可销毁
  ├── 动态分配、复用
  └── 成本可控
```

### 2. 容器热池机制

```
空闲时：5 个容器全部 idle
用户对话 → 分配 Pod A → 标记 busy
再次对话 → 复用 Pod A（会话保持）
会话结束 → 释放 Pod A → 恢复 idle
```

**优势**：
- ✅ 响应快速（无需冷启动）
- ✅ 资源高效（容器复用）
- ✅ 支持并发（多容器并行）
- ✅ 成本可控（少量容器支撑多用户）

### 3. 按智能体目录组织

```
lobsters/agents/
├── agent-1-1775816603/    # 智能体 1 的工作空间
│   ├── config.json
│   ├── memory/
│   └── files/
├── agent-2-1775817382/    # 智能体 2 的工作空间
│   ├── config.json
│   ├── memory/
│   └── files/
└── ...                     # 支持无限多智能体
```
