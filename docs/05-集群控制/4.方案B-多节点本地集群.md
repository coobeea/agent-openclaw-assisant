# 方案 B：多节点本地集群

> 使用 Kind 或 K3d 在本地创建多节点 K8s 集群，完整模拟生产环境

---

## 📋 方案概述

### 目标
- 在本地创建真正的多节点 K8s 集群
- 验证跨节点调度、负载均衡、故障转移
- 完全模拟生产环境的 K8s 特性
- 为上云做准备（配置可直接迁移）

### 与方案 A 的区别

| 对比项 | 方案 A（单节点） | 方案 B（多节点） |
|--------|----------------|----------------|
| **节点数** | 1 个 | 3-5 个 |
| **Pod 调度** | 全在一个节点 | 分布在多个节点 ✅ |
| **负载均衡** | 无法测试 | 可以测试 ✅ |
| **节点故障** | 无法模拟 | 可以模拟 ✅ |
| **网络策略** | 简化 | 真实的跨节点网络 ✅ |
| **存储** | 本地存储 | 可测试分布式存储 ✅ |
| **资源需求** | 4GB 内存 | 8-16GB 内存 |

## 🛠️ 方案选择：Kind vs K3d

### Kind（推荐）

**Kubernetes in Docker**，官方工具，功能完整

```bash
# 优点：
✅ 官方支持，稳定可靠
✅ 完整的 K8s 功能
✅ 社区活跃，文档详细
✅ 适合 CI/CD 测试

# 缺点：
❌ 资源占用较高
❌ 启动稍慢（30-60 秒）
```

### K3d（备选）

**K3s in Docker**，轻量级 K8s

```bash
# 优点：
✅ 资源占用少（内存省 50%）
✅ 启动快（10-20 秒）
✅ 内置负载均衡器
✅ 适合本地开发

# 缺点：
❌ 功能稍简化（K3s）
❌ 和生产 K8s 有细微差异
```

## 🔧 第二步：创建多节点集群

### 使用 Kind 创建集群

```bash
# 创建集群配置文件
cat > kind-cluster-config.yaml <<'EOF'
kind: Cluster
apiVersion: kind.x-k8s.io/v1alpha4
name: openclaw-cluster

# 节点配置
nodes:
  # 1 个 Master 节点
  - role: control-plane
    kubeadmConfigPatches:
    - |
      kind: InitConfiguration
      nodeRegistration:
        kubeletExtraArgs:
          node-labels: "node-role=master"
    extraPortMappings:
    - containerPort: 30080  # 调度服务
      hostPort: 30080
    - containerPort: 30000  # 其他服务
      hostPort: 30000

  # 3 个 Worker 节点
  - role: worker
    kubeadmConfigPatches:
    - |
      kind: JoinConfiguration
      nodeRegistration:
        kubeletExtraArgs:
          node-labels: "node-role=worker,workload=openclaw"
  
  - role: worker
    kubeadmConfigPatches:
    - |
      kind: JoinConfiguration
      nodeRegistration:
        kubeletExtraArgs:
          node-labels: "node-role=worker,workload=openclaw"
  
  - role: worker
    kubeadmConfigPatches:
    - |
      kind: JoinConfiguration
      nodeRegistration:
        kubeletExtraArgs:
          node-labels: "node-role=worker,workload=storage"

# 网络配置
networking:
  apiServerAddress: "127.0.0.1"
  apiServerPort: 6443
  podSubnet: "10.244.0.0/16"
  serviceSubnet: "10.96.0.0/16"
EOF

# 创建集群
kind create cluster --config kind-cluster-config.yaml

# 验证
kubectl cluster-info --context kind-openclaw-cluster
kubectl get nodes

# 输出应该有 4 个节点：
# NAME                            STATUS   ROLES           AGE
# openclaw-cluster-control-plane  Ready    control-plane   2m
# openclaw-cluster-worker         Ready    <none>          2m
# openclaw-cluster-worker2        Ready    <none>          2m
# openclaw-cluster-worker3        Ready    <none>          2m
```

### 使用 K3d 创建集群（备选）

```bash
# 创建 4 节点集群（1 master + 3 worker）
k3d cluster create openclaw \
  --servers 1 \
  --agents 3 \
  --port "30080:30080@loadbalancer" \
  --port "30000:30000@loadbalancer" \
  --k3s-arg "--disable=traefik@server:0"

# 验证
kubectl get nodes

# 输出：
# NAME                   STATUS   ROLES                  AGE
# k3d-openclaw-server-0  Ready    control-plane,master   1m
# k3d-openclaw-agent-0   Ready    <none>                 1m
# k3d-openclaw-agent-1   Ready    <none>                 1m
# k3d-openclaw-agent-2   Ready    <none>                 1m
```

## 💻 第五步：部署调度服务（增强版）

### 创建调度服务代码（支持多节点）

```bash
mkdir -p scheduler-service-v2
cd scheduler-service-v2

cat > scheduler.py <<'EOF'
from flask import Flask, request, jsonify
from kubernetes import client, config
import random
import time
import os

app = Flask(__name__)

# 加载 K8s 配置
try:
    config.load_incluster_config()  # Pod 内
except:
    config.load_kube_config()  # 本地开发

v1 = client.CoreV1Api()

# 容器池状态（生产环境应该用 Redis）
pool_status = {}
agent_sessions = {}  # agent_id -> container 映射（会话保持）

@app.route('/health')
def health():
    return jsonify({'status': 'healthy'})

@app.route('/allocate', methods=['POST'])
def allocate_container():
    """分配容器给智能体（支持会话保持）"""
    data = request.json
    agent_id = data.get('agent_id')
    
    if not agent_id:
        return jsonify({'error': 'agent_id required'}), 400
    
    # 检查是否有现有会话（会话保持）
    if agent_id in agent_sessions:
        existing_container = agent_sessions[agent_id]
        # 验证容器是否还存在
        try:
            pod = v1.read_namespaced_pod(
                name=existing_container,
                namespace='openclaw'
            )
            if pod.status.phase == 'Running':
                return jsonify({
                    'container': existing_container,
                    'agent_id': agent_id,
                    'status': 'reused',
                    'node': pod.spec.node_name
                })
        except:
            # 容器不存在，删除会话
            del agent_sessions[agent_id]
            if existing_container in pool_status:
                del pool_status[existing_container]
    
    # 获取所有 openclaw-pool 的 Pod
    pods = v1.list_namespaced_pod(
        namespace='openclaw',
        label_selector='app=openclaw-pool'
    )
    
    # 找到空闲的 Pod
    idle_pods = []
    for pod in pods.items:
        pod_name = pod.metadata.name
        if pod.status.phase == 'Running':
            if pod_name not in pool_status or pool_status[pod_name]['status'] == 'idle':
                idle_pods.append({
                    'name': pod_name,
                    'node': pod.spec.node_name,
                    'ip': pod.status.pod_ip
                })
    
    if not idle_pods:
        return jsonify({'error': 'No available containers'}), 503
    
    # 随机选择一个空闲 Pod
    selected = random.choice(idle_pods)
    selected_pod = selected['name']
    
    # 更新状态
    pool_status[selected_pod] = {
        'status': 'busy',
        'agent_id': agent_id,
        'allocated_at': time.time(),
        'node': selected['node']
    }
    agent_sessions[agent_id] = selected_pod
    
    return jsonify({
        'container': selected_pod,
        'agent_id': agent_id,
        'status': 'allocated',
        'node': selected['node'],
        'ip': selected['ip']
    })

@app.route('/release', methods=['POST'])
def release_container():
    """释放容器回池子"""
    data = request.json
    container = data.get('container')
    agent_id = data.get('agent_id')
    
    if container in pool_status:
        pool_status[container] = {
            'status': 'idle',
            'agent_id': None,
            'released_at': time.time()
        }
    
    if agent_id and agent_id in agent_sessions:
        del agent_sessions[agent_id]
    
    return jsonify({'status': 'released', 'container': container})

@app.route('/status', methods=['GET'])
def get_status():
    """查看池子状态（含节点信息）"""
    # 获取实时 Pod 状态
    pods = v1.list_namespaced_pod(
        namespace='openclaw',
        label_selector='app=openclaw-pool'
    )
    
    pods_by_node = {}
    for pod in pods.items:
        node = pod.spec.node_name
        if node not in pods_by_node:
            pods_by_node[node] = []
        
        pod_name = pod.metadata.name
        status = pool_status.get(pod_name, {'status': 'idle', 'agent_id': None})
        
        pods_by_node[node].append({
            'pod': pod_name,
            'status': status.get('status', 'idle'),
            'agent_id': status.get('agent_id'),
            'phase': pod.status.phase
        })
    
    return jsonify({
        'pool_status': pool_status,
        'agent_sessions': agent_sessions,
        'pods_by_node': pods_by_node,
        'total_pods': len(pods.items)
    })

@app.route('/nodes', methods=['GET'])
def get_nodes():
    """查看集群节点信息"""
    nodes = v1.list_node()
    
    node_info = []
    for node in nodes.items:
        node_info.append({
            'name': node.metadata.name,
            'status': node.status.conditions[-1].type if node.status.conditions else 'Unknown',
            'labels': node.metadata.labels,
            'capacity': {
                'cpu': node.status.capacity.get('cpu'),
                'memory': node.status.capacity.get('memory')
            }
        })
    
    return jsonify({'nodes': node_info})

if __name__ == '__main__':
    app.run(host='0.0.0.0', port=8080, debug=True)
EOF

# requirements.txt
cat > requirements.txt <<'EOF'
flask==3.0.0
kubernetes==28.1.0
EOF

# Dockerfile
cat > Dockerfile <<'EOF'
FROM python:3.11-slim

WORKDIR /app

COPY requirements.txt .
RUN pip install --no-cache-dir -r requirements.txt

COPY scheduler.py .

CMD ["python", "scheduler.py"]
EOF
```

```bash
kubectl get pods -n openclaw -l app=openclaw-pool -o wide -w

# 恢复节点
kubectl uncordon openclaw-cluster-worker
```

```bash
#!/bin/bash

  (

done

wait

EOF

chmod +x test-load-balance.sh
```
