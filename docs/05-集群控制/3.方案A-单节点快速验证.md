> 在 macOS 上使用 Docker Desktop K8s 或 Minikube，快速验证架构可行性

## 📋 方案概述

### 目标
- 1-2 天内搭建完整的验证环境
- 验证容器热池、调度、数据持久化等核心机制

## 🛠️ 第一步：环境准备

### 检查现有环境

你已经安装了：
- ✅ Docker (29.0.1)
- ✅ kubectl (v1.34.1)

### 选择 K8s 方案

#### 方案 1：Docker Desktop K8s（推荐，最简单）

```bash
# 1. 打开 Docker Desktop
# 2. Settings → Kubernetes → 勾选 "Enable Kubernetes"
# 3. 点击 "Apply & Restart"
# 4. 等待 5-10 分钟，直到状态显示 "Kubernetes is running"

# 验证
kubectl cluster-info
# 输出应该包含：
# Kubernetes control plane is running at https://kubernetes.docker.internal:6443
```

**优点**：
- ✅ 最简单，点几下就好
- ✅ 和 Docker 集成完美
- ✅ 不需要额外安装

**缺点**：
- ❌ 启动较慢（5-10 分钟）
- ❌ 资源占用稍高

#### 方案 2：Minikube（备选）

```bash
# 1. 安装 Minikube
brew install minikube

# 2. 启动集群（使用 Docker 驱动）
minikube start \
  --driver=docker \
  --memory=8192 \
  --cpus=4 \
  --disk-size=20g

# 3. 验证
kubectl get nodes
# 输出：
# NAME       STATUS   ROLES           AGE   VERSION
# minikube   Ready    control-plane   1m    v1.31.0

# 4. 启用 Ingress（可选）
minikube addons enable ingress
```

**优点**：
- ✅ 功能更全（内置很多插件）
- ✅ 启动快（1-2 分钟）
- ✅ 资源占用可调

**缺点**：
- ❌ 需要单独安装
- ❌ 需要记住 minikube 命令

## 💻 第五步：部署调度服务

### 创建调度服务代码

```bash
# 创建调度服务目录
mkdir -p scheduler-service
cd scheduler-service

# 创建 Python 调度服务
cat > scheduler.py <<'EOF'
from flask import Flask, request, jsonify
from kubernetes import client, config
import random
import time

app = Flask(__name__)

# 加载 K8s 配置
config.load_incluster_config()  # 在 Pod 内运行
v1 = client.CoreV1Api()

# 容器池状态（简化版，生产环境应该用 Redis）
pool_status = {}

@app.route('/health')
def health():
    return jsonify({'status': 'healthy'})

@app.route('/allocate', methods=['POST'])
def allocate_container():
    """分配容器给智能体"""
    data = request.json
    agent_id = data.get('agent_id')
    
    if not agent_id:
        return jsonify({'error': 'agent_id required'}), 400
    
    # 获取所有 openclaw-pool 的 Pod
    pods = v1.list_namespaced_pod(
        namespace='openclaw',
        label_selector='app=openclaw-pool'
    )
    
    # 找到空闲的 Pod
    idle_pods = []
    for pod in pods.items:
        if pod.metadata.name not in pool_status or pool_status[pod.metadata.name] == 'idle':
            idle_pods.append(pod.metadata.name)
    
    if not idle_pods:
        return jsonify({'error': 'No available containers'}), 503
    
    # 随机选择一个
    selected_pod = random.choice(idle_pods)
    pool_status[selected_pod] = f'busy-{agent_id}'
    
    return jsonify({
        'container': selected_pod,
        'agent_id': agent_id,
        'status': 'allocated'
    })

@app.route('/release', methods=['POST'])
def release_container():
    """释放容器回池子"""
    data = request.json
    container = data.get('container')
    
    if container in pool_status:
        pool_status[container] = 'idle'
    
    return jsonify({'status': 'released', 'container': container})

@app.route('/status', methods=['GET'])
def get_status():
    """查看池子状态"""
    return jsonify({'pool_status': pool_status})

if __name__ == '__main__':
    app.run(host='0.0.0.0', port=8080)
EOF

# 创建 requirements.txt
cat > requirements.txt <<'EOF'
flask==3.0.0
kubernetes==28.1.0
EOF

# 创建 Dockerfile
cat > Dockerfile <<'EOF'
FROM python:3.11-slim

WORKDIR /app

COPY requirements.txt .
RUN pip install --no-cache-dir -r requirements.txt

COPY scheduler.py .

CMD ["python", "scheduler.py"]
EOF
```

### 构建并部署调度服务

```bash
# 构建镜像
docker build -t openclaw-scheduler:latest .

# 如果使用 Minikube
minikube image load openclaw-scheduler:latest

# 创建 K8s 部署配置
cat > ../k8s-manifests/scheduler-deployment.yaml <<'EOF'
apiVersion: v1
kind: ServiceAccount
metadata:
  name: openclaw-scheduler
  namespace: openclaw
---
apiVersion: rbac.authorization.k8s.io/v1
kind: Role
metadata:
  name: pod-reader
  namespace: openclaw
rules:
- apiGroups: [""]
  resources: ["pods"]
  verbs: ["get", "list", "watch"]
---
apiVersion: rbac.authorization.k8s.io/v1
kind: RoleBinding
metadata:
  name: openclaw-scheduler-binding
  namespace: openclaw
subjects:
- kind: ServiceAccount
  name: openclaw-scheduler
roleRef:
  kind: Role
  name: pod-reader
  apiGroup: rbac.authorization.k8s.io
---
apiVersion: apps/v1
kind: Deployment
metadata:
  name: openclaw-scheduler
  namespace: openclaw
spec:
  replicas: 1
  selector:
    matchLabels:
      app: openclaw-scheduler
  template:
    metadata:
      labels:
        app: openclaw-scheduler
    spec:
      serviceAccountName: openclaw-scheduler
      containers:
      - name: scheduler
        image: openclaw-scheduler:latest
        imagePullPolicy: IfNotPresent
        ports:
        - containerPort: 8080
---
apiVersion: v1
kind: Service
metadata:
  name: openclaw-scheduler
  namespace: openclaw
spec:
  type: NodePort
  selector:
    app: openclaw-scheduler
  ports:
  - protocol: TCP
    port: 8080
    targetPort: 8080
    nodePort: 30080
EOF

# 部署
kubectl apply -f ../k8s-manifests/scheduler-deployment.yaml

# 验证
kubectl get pods -n openclaw -l app=openclaw-scheduler
```

## 🔧 常见问题

### 问题 1：Pod 启动失败（ImagePullBackOff）

```bash
# 原因：镜像拉取失败
# 解决：
# 1. 确认镜像已构建
docker images | grep openclaw

# 2. 如果使用 Minikube，加载镜像
minikube image load openclaw:hotpool

# 3. 修改 Deployment，设置 imagePullPolicy: IfNotPresent
kubectl edit deployment openclaw-pool -n openclaw
```

### 问题 2：调度服务无法访问 K8s API

```bash
# 原因：权限不足
# 解决：确认 ServiceAccount 和 RBAC 配置正确
kubectl get serviceaccount openclaw-scheduler -n openclaw
kubectl get role pod-reader -n openclaw
kubectl get rolebinding openclaw-scheduler-binding -n openclaw
```

### 问题 3：端口转发连接失败

```bash
# 检查 Pod 是否正常运行
kubectl get pods -n openclaw

# 查看 Pod 日志
```
