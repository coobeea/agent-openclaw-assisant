# OpenClaw 前端界面

基于 Vue 3 + Element Plus 的智能体管理平台

## 功能

- ✅ 用户注册/登录
- ✅ 创建智能体
- ✅ 智能体列表
- ✅ 实时对话
- ✅ 对话历史

## 本地开发

```bash
# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 访问 http://localhost:3001
```

## 构建部署

```bash
# 构建生产版本
npm run build

# 构建 Docker 镜像
docker build -t openclaw-frontend:v1 .
```
